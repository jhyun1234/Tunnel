Assets/Audio/Emerge — 괴물(그것)이 숨은 굴에서 벽 틈 · 천장 구멍으로 나오는 소리 (GAME-1 판정 7 · 8, 사용자 2026-10-05).
사용자 판정(2026-10-05): "돌가루 소리는 5개정도 묶어서 사운드를 혼합" → 섞기 후보 A · B · C 를 들은 뒤 "B A A" (돌가루 B · 와르르 A · 긁힘 A).
원본은 저장소에 없다 — 아래 주소에서 다시 받아 build/refs/snd/emerge/ 에 두고 `python tools/snd_emerge.py --game B A A` 로 만든다(같은 원본이면 같은 파일).
라이선스: 전부 Creative Commons 0 (CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/) — 표기 의무 없음. 받은 날짜 2026-10-05.
Freesound 는 로그인 없이 받는 hq mp3 미리듣기, BigSoundBank 는 원본 WAV(라이선스 페이지 https://bigsoundbank.com/licenses.html "Creative Commons CC0 1.0 Universal").
