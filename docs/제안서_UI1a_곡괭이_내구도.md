# 제안서 UI-1a — 곡괭이 내구도 (닳으면 손이 떨리고, 0 이면 못 캔다)

작성 2026-09-16. 출처: `docs/design/ui_ux_design.md` Step 2 표 첫 줄 · Step 6(DevHud 3·4 키) · Step 7 UI-1 ①. 값은 HANDOFF M6 제안값(100 · 타격 −1 · 던지기 −5)을 그대로 쓴다. UI-1 은 설계서에 ①~④ 네 가지가 묶여 있지만 **하나씩 낸다**(사용자 규칙) — 이번은 ① 내구도만. 남은 것: ② 지쳤을 때 자세 · ③ 화면 글자 0 · ④ DevHud 시작 시 끄기.

## 무엇을 하려는지
곡괭이가 쓸수록 닳는다. 숫자는 화면에 안 보인다. 대신 **얼마 안 남으면(15 이하) 칠 때마다 손에 든 곡괭이가 0.5초 떨린다.** 0 이 되는 순간 **곡괭이가 손에서 조각조각 깨져 바닥에 떨어졌다가 사라진다**(사용자 09-16 결정). 그 뒤는 빈손 — 못 캐고 못 던진다. **고치는 방법은 없다.** 새 곡괭이는 상점 판(나중)에서 산다. 재미 문장의 "돈이 벌린다" 쪽 비용 — 3대 맞서는 것도, 던지는 것도 곡괭이를 깎아 먹는다. 42 m 판에서는 DevHud 키로 채운다.

## 어떻게 만들 것인지
- **닳음** (`Pickaxe.cs`): `durability` 100 에서 시작. 포켓이나 괴물에 **닿은** 타격마다 −1(허공은 안 닳음), 던지기마다 −5. 0 밑으로 안 내려간다.
- **떨림**: 내구도 ≤ PICK_SHAKY_BELOW 15 이면 닿은 타격 뒤 0.5 초 동안 뷰모델 자리에 무작위 흔들림(폭 0.04 m = 걸을 때 흔들림의 2배). 화면(머리)은 안 흔들린다 — 곡괭이만.
- **0 = 부서짐** (`Pickaxe.Break`): 0 이 되는 그 타격 직후 뷰모델이 즉시 사라지고(`hasPick=false`, 던진 뒤 빈손과 같은 길), 손 자리에서 곡괭이 재질 조각 PICK_BREAK_PIECES 8 개가 PICK_BREAK_POP 1.5 m/s 로 튀어 나온다. 조각은 자갈 튀는 코드(`MiningFx.Chips`)를 그대로 빌린 세계 물체라 진짜로 바닥에 떨어져 구르고, PICK_BREAK_LIFE 1.5 s 놓였다가 줄어들며 사라진다(자갈과 같은 `FadeOut`). 떨림 없이 바로 깨진다. 빈손이라 좌클릭·우클릭 아무 일 없고, 바닥에 주울 것도 없다. 던져서 0 이 되면(예: 3 남았을 때 던지기 −5) 주워 드는 순간 손에서 깨진다. 부서지는 소리는 사운드 S5 때 — 이번엔 무음.
- **DevHud**: 플레이어 줄에 `pick 100/100 held|thrown|broken` 표시, `3` −10 · `4` +10 (설계서 Step 6 키). `3` 으로 0 이 되면 손에서 깨지고, 깨진 뒤 `4` 로 올리면 손에 다시 난다(상점이 생기기 전 판정용).
- **검사** `-only pick`: ① 포켓 10번 치면 100 → 90 ② 한 번 던지고 주우면 −5 ③ 내구도를 15 로 놓고 치면 뷰모델이 0.5 초 안에 0.02 m 이상 움직였다 걷지 않을 때 · 40 이면 안 움직인다 ④ 1 로 놓고 포켓을 치면 0 → 손이 비고(뷰모델 꺼짐·던진 곡괭이 없음) 조각 8 개가 생겼다가 4 s 안에 0 개 · 빈손으로 포켓 앞 좌클릭 0.6 s → 포켓 체력 그대로·소음 0, 우클릭 → 던진 곡괭이 안 생김 · `+100`(DevHud 4 키와 같은 길) → 손에 다시 남. 사보타주: `nodull`(안 닳음 → ①②) · `steadyhands`(떨림 없음 → ③) · `everlasting`(0 이어도 손에 남고 캐짐 → ④).

## 정할 수치
| 항목 | 값 | 출처 |
|---|---|---|
| PICK_DURABILITY_MAX | 100 | HANDOFF M6 제안값 (Unity 전용) |
| PICK_WEAR_HIT · PICK_WEAR_THROW | 1 · 5 | 같은 곳. 캐기 한 번 = 2타 = 2 → 곡괭이 하나로 50번 캔다 |
| PICK_SHAKY_BELOW | 15 | 설계서 Step 2 "지금" 단계 (타격 15번 = 캐기 7번, "돌아갈까"를 정할 양) |
| PICK_SHAKE_AMOUNT · PICK_SHAKE_S | 0.04 m · 0.5 s | 설계서 제안값(걸을 때 흔들림 0.02 의 2배) |
| PICK_BREAK_PIECES · PICK_BREAK_POP · PICK_BREAK_LIFE | 8 · 1.5 m/s · 1.5 s | 제안값. 자갈(2개·2.4 m/s·1.2 s)보다 많고 느리게 — 손에서 흘러내리는 느낌. 판정 뒤 조정 |

## 안 하는 것
날 모양 3단계(3D 요청 뒤) · 둔탁한 타격음·자루 삐걱·부서지는 소리(사운드 S5) · 새 곡괭이 사기(상점 판) · 고치기(없음 — 결정) · "곧" 단계(40~15) 표시 — 날 모양이 없으면 보여줄 것이 없어 이번엔 떨림 + 부서짐으로 판정한다.

## 물어볼 것 (판정 때)
1. 숫자 없이 떨림만 보고 "곧 부러진다"를 알 수 있는가
2. 떨림 폭(0.04 m)과 시간(0.5 초)이 알아볼 만한가, 거슬리는가
3. 조각나 떨어지는 것이 "부러졌다"로 읽히는가 — 조각 수(8)·튀는 세기·바닥에 놓이는 시간(1.5 s)이 알맞은가
4. 50번 캐면 끝나는 양이 한 판에 맞아 보이는가 (상점이 생기기 전 감만)
