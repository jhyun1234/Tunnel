# 제안서 UI-1a — 곡괭이 내구도 (닳으면 손이 떨리고, 0 이면 못 캔다)

작성 2026-09-16. 출처: `docs/design/ui_ux_design.md` Step 2 표 첫 줄 · Step 6(DevHud 3·4 키) · Step 7 UI-1 ①. 값은 HANDOFF M6 제안값(100 · 타격 −1 · 던지기 −5)을 그대로 쓴다. UI-1 은 설계서에 ①~④ 네 가지가 묶여 있지만 **하나씩 낸다**(사용자 규칙) — 이번은 ① 내구도만. 남은 것: ② 지쳤을 때 자세 · ③ 화면 글자 0 · ④ DevHud 시작 시 끄기.

## 무엇을 하려는지
곡괭이가 쓸수록 닳는다. 숫자는 화면에 안 보인다. 대신 **얼마 안 남으면(15 이하) 칠 때마다 손에 든 곡괭이가 0.5초 떨린다.** 0 이 되면 휘둘러도 허공이고(광물도 괴물도 안 맞음) 던지지도 못한다. 재미 문장의 "돈이 벌린다" 쪽 비용 — 3대 맞서는 것도, 던지는 것도 곡괭이를 깎아 먹는다. 새 곡괭이는 상점 판(나중)에서. 42 m 판에서는 DevHud 키로 채운다.

## 어떻게 만들 것인지
- **닳음** (`Pickaxe.cs`): `durability` 100 에서 시작. 포켓이나 괴물에 **닿은** 타격마다 −1(허공은 안 닳음), 던지기마다 −5. 0 밑으로 안 내려간다.
- **떨림**: 내구도 ≤ PICK_SHAKY_BELOW 15 이면 닿은 타격 뒤 0.5 초 동안 뷰모델 자리에 무작위 흔들림(폭 0.04 m = 걸을 때 흔들림의 2배). 화면(머리)은 안 흔들린다 — 곡괭이만.
- **0**: `Strike` 가 아무것도 안 친다(휘두르는 동작·소리 없음, 소음 없음). 우클릭 던지기 무시.
- **DevHud**: 플레이어 줄에 `pick 100` 표시, `3` −10 · `4` +10 (설계서 Step 6 키).
- **검사** `-only pick`: ① 포켓 10번 치면 100 → 90 ② 한 번 던지고 주우면 −5 ③ 내구도를 15 로 놓고 치면 뷰모델이 0.5 초 안에 0.02 m 이상 움직였다 걷지 않을 때 · 40 이면 안 움직인다 ④ 0 으로 놓고 포켓 앞에서 좌클릭 → 포켓 체력 그대로·소음 0, 우클릭 → 곡괭이 그대로 손에. 사보타주: `nodull`(안 닳음 → ①②) · `steadyhands`(떨림 없음 → ③) · `everlasting`(0 이어도 캐짐 → ④).

## 정할 수치
| 항목 | 값 | 출처 |
|---|---|---|
| PICK_DURABILITY_MAX | 100 | HANDOFF M6 제안값 (Unity 전용) |
| PICK_WEAR_HIT · PICK_WEAR_THROW | 1 · 5 | 같은 곳. 캐기 한 번 = 2타 = 2 → 곡괭이 하나로 50번 캔다 |
| PICK_SHAKY_BELOW | 15 | 설계서 Step 2 "지금" 단계 (타격 15번 = 캐기 7번, "돌아갈까"를 정할 양) |
| PICK_SHAKE_AMOUNT · PICK_SHAKE_S | 0.04 m · 0.5 s | 설계서 제안값(걸을 때 흔들림 0.02 의 2배) |

## 안 하는 것
날 모양 3단계(3D 요청 뒤) · 둔탁한 타격음·자루 삐걱(사운드 S5) · 새 곡괭이 사기(상점 판) · "곧" 단계(40~15) 표시 — 날 모양이 없으면 보여줄 것이 없어 이번엔 떨림 하나로만 판정한다(설계서 UI-1 ① 그대로).

## 확인 목록 (F5)
- [ ] 포켓을 여러 번 치면 DevHud 의 pick 숫자가 1씩 준다, 던지면 5 준다
- [ ] `3` 키로 15 이하로 내리면 칠 때마다 곡괭이가 떨린다
- [ ] 0 이면 휘둘러도 안 캐지고 던져지지 않는다, `4` 키로 올리면 다시 된다
- [ ] `bash tools/build.sh -only pick` PASS, `-sabotage nodull`·`steadyhands`·`everlasting` FAIL

## 물어볼 것 (판정 때)
1. 숫자 없이 떨림만 보고 "곧 부러진다"를 알 수 있는가
2. 떨림 폭(0.04 m)과 시간(0.5 초)이 알아볼 만한가, 거슬리는가
3. 0 이 됐을 때 "왜 안 캐지지?"가 아니라 "부러졌다"로 읽히는가 — 안 읽히면 무엇이 필요한가
4. 50번 캐면 끝나는 양이 한 판에 맞아 보이는가 (상점이 생기기 전 감만)
