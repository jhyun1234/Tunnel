## 무엇을 Meshy 로, 무엇은 아닌지

**벽·천장·바닥은 Meshy 로 뽑지 않는 걸 추천한다.** 이유 셋 — ① 조각은 7 m 칸에 정점이 딱 맞아야 이어진다(검사 `seam_gap_under_5mm`). Meshy 는 한 덩어리 그물을 주고 가장자리가 격자에 안 맞는다. ② 코드가 찾는 노드(`SHL_` · `COL_` · `SLOT_` · `TMB_`)를 다시 만들어야 하고, 벽 틈 자르기(`make_gaps.py`)도 다시 짜야 한다. ③ 조각 8종(곧은 길 · 굽이 · T · 십자 · 목 · 막힘 · 대피소 · 방 2)을 다 뽑아야 조립기가 돈다 — 종류마다 이음새 손질이 따라온다.
대신 **벽의 겉을 바꾸는 두 가지 싼 길**: ⓐ 바위 덩어리·무너진 돌무더기·벽에 박힌 광맥 같은 "붙이는 소품"을 Meshy 로 뽑아 지금 벽 위에 얹는다(조각 안 `PRP_straight_rock_*` 자리, 코드 안 바뀜) ⓑ 벽·바닥 그림을 Poly Haven 의 다른 CC0 그림으로 바꿔 본다(0 크레딧). 그래도 껍데기째 바꾸고 싶으면 2차에서 곧은 길 조각 하나만 뽑아 Blender 에서 7 m 격자에 맞추고 노드를 붙여 보는 시험을 먼저 한다(물음 1).

**나머지는 전부 Meshy 로 뽑되, 뽑기 전에 CC0 가 있는지 먼저 본다**(Poly Haven → Sketchfab CC0 → Meshy). Meshy 는 광산 전용 물건(광차 · 갱목 · 레일 · 환기구 · 리프트 · 곡괭이)에 쓰고, 어디에나 있는 물건(안전모 · 통 · 상자 · 삽)은 CC0 를 먼저 찾는다.

## 파이프라인

1. **그림**: 물품마다 정면 1장(+ 옆 1장). 지금까지처럼 Gemini 로 그리면 상업 문장 미확인 문제가 그대로 따라온다 → **소품은 문장만으로(텍스트 → 3D) 먼저 뽑아 보고**, 모양이 안 나오는 것만 그림을 쓴다(물음 2). 프롬프트는 `Documents/MineTunnel/IMAGE_PROMPTS.md` 에 절을 더한다.
2. **뽑기**: `gen_meshy.py` 에 `--text "…"`(텍스트 → 3D, 미리보기 → 다듬기 두 단계) · `--poly`(물품별 면 예산) · `--tex 2k` 를 더한다. 결과는 `Documents/MineTunnel/mesh/props/meshy_<이름>.glb`, 뽑을 때마다 `MINER_ASSET_PIPELINE.md` 기록 표 한 줄(지금과 같음).
3. **맞춤** (새 스크립트 `blender/props/fit_prop.py`, 물품 표 하나로 전부): 긴 축 → 표의 실제 크기로 배율 · 원점을 바닥 가운데로 · Z 위 · 면 수가 예산을 넘으면 Decimate · 그림 4K → 1K(`tools/shrink_glb.py` 다시 씀) · 노드 이름 `PRP_<이름>` · 충돌이 필요한 것(광차 · 상자 · 통)만 볼록 상자 `COL_<이름>` → `Assets/Tunnel/Props/<이름>.glb`. 갱목은 `blender/map/` 에서 `piece_straight` 의 `TMB_*` 그물만 새것으로 바꿔 **새 파일** `piece_straight_v2.gltf` 로(원본은 안 덮어쓴다 — `make_gaps.py` 처럼).
4. **배치**: 1차는 `BuildM1.MakeScene` 이 `Tuning.PROPS`(이름 · 조각 번호 · 자리 · 돌림) 표대로 복도에 놓는다. 조립기(조각 23종)가 생기면 그쪽 소품 무더기 규칙으로 옮긴다.
5. **판정**: 실행 파일에서 F5. 물품마다 캡처 `24_prop_<이름>.png`(램프 2 m 정면, 검사가 찍는다).

## 만드는 차례

1. **1차 = 곡괭이 + 갱목 세트 + 전등** (3개, ~100 크레딧). `gen_meshy.py --text` 확장 → 세 개 뽑기 → `fit_prop.py` → `piece_straight_v2` → 검사 6개 + 사보타주 FAIL 확인 → 전체 `build.sh` → 커밋 → **F5 판정**(곡괭이는 손에 든 채, 갱목은 복도를 걸으며).
2. 판정 뒤 2차 = 레일 + 광차 + 벽 붙이는 소품(4·5·11). 광차는 Godot 것과 나란히 놓고 고른다.
3. 3차 = 배수관 · 환기구 · 안전모 · 안전도구 · 리프트(6~10, CC0 먼저).
4. (물음 1 이 "해 본다"면) 껍데기 시험: 곧은 길 하나.

## 물어볼 것

1. 벽·천장·바닥 — 추천대로 **껍데기는 두고 붙이는 소품 + 그림 교체**로 갈지, 아니면 2차에서 **곧은 길 하나를 Meshy 로 뽑아 격자에 맞추는 시험**을 할지(30 크레딧 + 하루).
2. 소품 그림 — 문장만으로(텍스트 → 3D) 먼저 시도해도 되나. 그림이 필요할 때 Gemini 를 계속 써도 되나(상업 문장 미확인 — 출시 전 정리 항목이 늘어난다).
3. "무기" — 무엇인가(둘째 곡괭이? 망치? 던지는 것?). 게임 규칙에 없는 무기는 모델만 있어도 쓸 곳이 없다 — 규칙이 먼저.
4. 1차 3개(곡괭이 · 갱목 · 전등)로 시작해도 되나, 아니면 광차를 1차에 넣나.
5. 광차·리프트·레일은 Godot 판 glTF 를 Unity 로 옮겨 **먼저 보고** Meshy 로 바꿀지 정해도 되나(0 크레딧, 반나절).
