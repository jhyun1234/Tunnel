# 제안서 3D-③ — 괴물이 하는 일마다 맞는 동작을 튼다 (동작 7개 연결)

작성 2026-09-18. 출처: 3D 설계서 Step 6 "3D-③ 클립 8개 Animator 연결"(`Opus5_채굴게임/docs/design/creature_env_3d_design.md`), 3D-① 제안서의 연결 안, HANDOFF 2절(09-18 괴물 겉모습 3D-①~②c 전부 통과).

## 지금 상태
- 괴물 모델에는 동작 14개가 들어 있고, 동작 목록 파일 `Assets/Settings/M8_StalkerAnim.controller` 에 14개가 칸으로 다 있다. 하지만 **무엇을 하든 `idle_crouch`(팔 벌리고 선 자세) 하나만 반복**한다. 걸어도, 달려도, 맞아도, 벽을 타도 같은 자세로 미끄러져 다닌다.
- 괴물의 행동(배회·조사·수색·들킴·추격·잡기·스턴·철수·벽타기·숨기)은 `Stalker.cs` 에 이미 있고 판정도 끝났다. 이번에는 **행동은 그대로 두고 몸 동작만 행동에 맞춘다.**

## 무엇을 어떤 동작에 붙이나

| 괴물이 하는 일 | 움직이는 빠르기 | 틀 동작 | 동작 원래 길이 | 어떻게 트나 |
|---|---|---|---|---|
| 배회 · 수색 걸음 · 빛 쪽으로 다가가기 | 2.5 m/s | `walk_crouch` (웅크려 걷기) | 4.07 s 한 바퀴 | 발이 바닥에서 안 미끄러지게 빠르기를 맞춘다(아래 "발 미끄러짐") |
| 소리 쪽으로 조사 · 추격 · 철수 달리기 | 5.0 · 6.5 · 4.0 m/s | `run` | 0.67 s 한 바퀴 | 같음 |
| 멈춰 있음 (배회 도착 1.0 s · 수색 들여다보기 2.0 s · 스턴 뒤 서서 봄) | 0 | `idle_crouch` | 4.33 s | 그대로 반복 |
| 들킴 (멈춰서 1.0 s 뒤 추격) | 0 | `roar` (포효) | 2.83 s | 2.83 s 중 **가장 크게 벌리는 순간이 들어가는 1.0 s 구간**만 튼다. 그 순간은 봇이 잰다(두 손 사이가 가장 먼 때) |
| 스턴 (곡괭이 한 대, 0.5 s) | 0.2 s 에 1.0 m 밀림 | `hit` | 2.03 s | 처음부터 0.5 s 만 틀고 바로 다음 동작으로 |
| 벽타기 (3.6 s, 1.2 m/s 로 위로) | 1.2 m/s | `crawl` (엎드려 기기) | 5.17 s | 몸을 90° 세워 **배가 벽에 붙고 머리가 위로** 가게 눕힌다. 빠르기는 발 미끄러짐과 같은 방법 |
| 잡기 | 0 | `attack_swipe` (팔 휘두르기) | 2.63 s | 잡는 순간 튼다. 화면이 0.3 s 만에 검어져서 지금은 앞 0.3 s 만 보인다 — 얼굴 쪽으로 카메라 돌리기는 시네마틱 몫 |
| 숨음 | — | 없음 | | 몸이 안 보인다 |

- 동작이 바뀔 때는 두 동작을 **0.2 s 겹쳐서** 부드럽게 넘긴다(포효·스턴은 빨리 들어가야 해서 0.1 s).
- `death` 는 연결 안 한다. 괴물이 안 죽어서 틀 자리가 없다(설계서도 "판정 항목엔 없음"). 쓸 자리가 생기면 그때 붙인다.
- 동작 목록 파일에 "이 다음엔 저것" 같은 연결 줄은 안 긋는다. 새 부품이 괴물의 지금 행동을 매 순간 보고 맞는 칸으로 바로 넘긴다 — 행동이 `Stalker.cs` 한 곳에만 있어서 두 곳이 어긋날 일이 없다.

## 발 미끄러짐 — 동작 빠르기를 움직이는 빠르기에 맞춘다
동작은 제자리 걸음으로 구워져 있다(몸은 코드가 옮긴다). 동작 빠르기와 몸이 실제로 가는 빠르기가 다르면 발이 얼음 위처럼 미끄러진다. Blender 에서 동작을 구울 때 원래 걸음 빠르기를 기록해 두었다(`Documents/MineTunnel/blender/stage5.log`): `walk_crouch` 0.45 · `run` 3.01 · `crawl` 0.57 m/s. 게임 괴물은 1.5배 크니 약 0.68 · 4.5 · 0.86 m/s.

| 괴물 빠르기 | 동작 | 몇 배로 틀어야 발이 안 미끄러지나 |
|---|---|---|
| 배회 2.5 m/s | `walk_crouch` | **약 3.7배** (4.07 s 한 바퀴가 1.1 s) |
| 철수 4.0 | `run` | 약 0.9배 |
| 조사 5.0 | `run` | 약 1.1배 |
| 추격 6.5 | `run` | 약 1.4배 |
| 벽타기 1.2 | `crawl` | 약 1.4배 |

**배회가 문제다.** 웅크려 걷기는 원래 아주 느린 살금 걸음이라 2.5 m/s 에 맞추면 3.7배로 종종걸음을 친다. 세 가지 안을 실행 파일에 다 넣고 **키로 바꿔 보며 고르게** 한다(판정값은 키로 직접 조절 — 전에 정한 방식):

| 안 | 모습 | 발 |
|---|---|---|
| A (추천) | 웅크려 걷기 3.7배 — 벌레처럼 빠르게 잔걸음 | 안 미끄러진다 |
| B | 달리기 0.56배 — 느린 달리기 | 안 미끄러진다 |
| C | 웅크려 걷기 2.0배로 멈추고 나머지는 미끄러짐 | 1.5 m/s 쯤 미끄러진다 |

배회 빠르기 2.5 자체는 안 바꾼다(괴물 행동 몫, M3 판정 뒤 그대로).

## 결정 변경 제안 1건 — 맞았을 때 몸이 납작해지는 것 없애기
M5 에서 통과한 피격 표시 "맞으면 몸이 0.3 s 동안 세로로 0.85배 납작해진다"는 캡슐 시절 것이다. 지금은 그게 **모델 전체를 고무처럼 찌그러뜨린다.** `hit` 동작이 그 자리를 대신하니 납작해지기는 없앤다(`Stalker.cs` 에서 그 줄만 뺌). 싫으면 남긴다 — 승인 때 답해 준다.

## 판정용 키 (실행 파일, DevHud)
- 지금 있는 **9 키**(괴물을 행동 끄고 내 앞 2.5 m 에 세움)를 누른 상태에서 **N 키 = 동작 차례로 바꾸기**(`idle_crouch` → `walk_crouch` → `run` → `roar` → `hit` → `crawl`(벽에 붙인 자세) → `attack_swipe`). 왼쪽 위에 동작 이름과 빠르기 배수가 뜬다. 숫자패드는 안 쓴다(N 은 글자 키).
- **U 키 = 배회 걸음 A → B → C 바꾸기.** 9 를 풀고(행동 켬) 걷는 괴물을 보며 고른다. 화면에 지금 안이 뜬다.
- 0 키(행동 끄고 켜기)·9 키는 그대로.

## 봇 검사 `bash tools/build.sh -only anim` (배포된 실행 파일에서)
1. **행동마다 맞는 동작**: 배회 걷기 → `walk_crouch`, 도착해 멈춤 → `idle_crouch`, 소리 조사 → `run`, 들킴 → `roar` 1.0 s 뒤 `run`, 스턴 → `hit`, 철수 → `run`, 벽타기 → `crawl`, 잡기 → `attack_swipe`. 틀어진 칸 이름을 읽어 대조한다.
2. **발 미끄러짐**: 걷기·달리기 중 바닥에 닿은 발(더 낮은 발끝 뼈)이 땅 위에서 움직이는 빠르기 평균 ≤ **0.3 m/s**(제안값 — 맞추지 않으면 배회에서 약 1.8 m/s). 뒤로 걷는 괴물도 이 검사에 걸린다(발이 거꾸로 밀려 두 배로 미끄러진다).
3. **벽타기 자세**: 머리 뼈가 엉덩이 뼈보다 위, 엉덩이가 벽에서 0.5 m 안, 모든 뼈가 벽 안쪽(벽을 안 뚫음).
4. **팔이 바닥·벽을 안 뚫음**: 걷기·달리기 중 두 손 뼈가 바닥 아래 5 cm 넘게 안 내려가고 벽 밖으로 안 나간다(설계서 Step 2 확인 항목).
5. **포효 창**: 두 손이 가장 멀어지는 순간이 들킴 1.0 s 안에 들어온다.
6. **fps ≥ 60** (RTX 5060 Ti).

사보타주 — 일부러 되살려서 FAIL 이 뜨는지 본다:
- `noanim`: 새 부품 끔(지금처럼 `idle_crouch` 만) → 1번 FAIL
- `slide`: 빠르기 맞추기 끔(늘 1배) → 2번 FAIL
- `uprightclimb`: 벽타기 때 몸을 안 세움 → 3번 FAIL

캡처: 동작마다 옆 2.5 m 에서 0.1 s 간격 연속 사진 한 장씩(`build/check_3d3/21_anim_{동작}_sheet.png`) + 7 m 에서 걸어오는 모습 0.1 s 간격. 사진으로 모자라면 간격을 줄여 더 찍는다. 모두 파일로 보낸다.
