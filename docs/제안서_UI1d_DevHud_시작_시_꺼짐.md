# 제안서 UI-1d — DevHud 시작 시 꺼짐 (실행하면 갱도 화면, F1 로 켠다)

작성 2026-09-16. 출처: `docs/design/ui_ux_design.md` Step 6(빌드 규칙: 배포 빌드에서 시작 시 `show = false`, F1 로 켠다, 사보타주 `hudon`) · Step 7 UI-1 ④. UI-1 네 가지 중 마지막 — ①②③ 은 09-16 통과.

## 무엇을 하려는지
실행 파일을 켜면 **아무 글자 없는 갱도 화면**으로 시작한다. 지금은 DevHud(왼쪽 위 숫자 4줄 + 소음 원)가 켜진 채 시작해서 F1 로 꺼야 한다. 판정용 화면은 필요할 때 F1 로 켜고, 다시 F1 로 끈다. 손잡이 키(3 4 5 6 · 0 · V · [ ] · - = · 1 2)는 화면이 꺼져 있어도 먹는다 — 값을 만지고 싶으면 F1 로 켜서 본다. 이유: UI-1c 로 갱도 화면 글자를 0 으로 만들었는데 시작할 때 켜져 있으면 첫 화면이 숫자판이다(설계서 기준 ①). 빼지는 않는다 — 판정은 배포물에서 하니까(설계서 Step 6).

## 어떻게 만들 것인지
- **`DevHud.cs`**: `show` 시작값을 `Tuning.DEVHUD_START_VISIBLE`(false) 에서 읽는다. 첫 Update 에서 한 번 적용(씬에 굽지 않게 `[NonSerialized]` 필드). F1 로 켜고 끄는 것·손잡이 키는 그대로.
- **검사** (`-only hud` 에 붙임): DevHud 컴포넌트를 켜고 한 프레임 → 화면 표시 없음(`DevHud.Visible` false) · F1 → 표시(소음 원도 그려진다, UI-1c ② 를 이 뒤로 옮김) · F1 → 다시 없음. 사보타주 `hudon`(시작값 true → 첫 항목 FAIL).

## 안 하는 것
DevHud 1줄의 "화면 밝기"(매 프레임 화면을 읽어야 해서 무겁다 — 필요하면 캡처 검사 값으로 본다) · `8` 괴물 정지·`9` 예약 키(괴물 마일스톤 때) · 4줄 게이지·사망(UI-3) · 아예 빼기(안 뺀다).
