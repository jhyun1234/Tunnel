## 어떻게 되나 (0 크레딧, 몸 점은 하나도 안 옮김)

### 1. 몸 (`PlayerSkin`, 1인칭 팔도 같은 재질)
- **부위별 윤기 그림** — 몸 색 그림에서 부위를 가른다(장갑 = 붉은 · 장화 = 아주 어두운 · 흰 소매 · 목수건 = 흰 · 나머지 = 옷). 부위마다 거칠기 ※(우리 판단, 판정 키로 고름): 옷 면 0.92 · 흰 면 0.95 · 고무 장화 0.55 · 고무 장갑 0.65 + 작은 얼룩(±0.05) → URP 쇠 · 매끈함 그림(`Textures/player_metal_smooth.png`, 2K, R = 쇠 0 · A = 1 − 거칠기).
- **가림 그림** — Blender 로 몸 + 소품을 함께 두고 그늘을 굽는다(2K, `Textures/player_ao.png`) → 탄띠 밑 · 겨드랑이 · 주머니 · 목수건 밑이 어두워진다.
- **천 결** — 무료 질감(CC0) 한 장을 옷 부위에만 작은 무늬로 되풀이(URP 재질의 "세부" 칸, 옷 부위만 켜는 그림 1 장). 원본 후보 = Poly Haven **denim_fabric** 1K(능직 — 면 작업복과 같은 짜임, CC0, 노멀 0.47 MB · 색 · 거칠기까지 1.8 MB) → **받기는 물을 것 1.** 장화 · 장갑 · 살에는 안 입힌다.
- **탄가루 · 때** — 원래 색 그림(`player_base.png`)은 그대로 두고 **때 묻힌 판을 새 파일 세 장**으로 굽는다(옅게 · 보통 · 짙게, `Textures/player_base_dirt{1,2,3}.png`): 가림이 짙은 오목한 곳 + 아래쪽(장화 밑 · 무릎 · 바지단) + 소매 끝 · 장갑 손바닥에 탄가루(검은 회색) · 넓게 옅은 얼룩(석탄 질감 Rock035 결, ART-1 에 이미 있음).

### 2. 소품 (안전모 · 램프 · 탄띠 · 수통 · 배터리 · 쇠붙이 · 방독면)
- `player_rig.py` 에서 UV 없는 소품에 상자 투영 UV 를 준다(점은 그대로) → `player.fbx` 다시.
- 재질 = ART-1 에서 이미 받은 CC0 질감(`build/art/cand_tex`: rusty_painted_metal · rusty_metal_03 · Rock035)과 천 결(denim_fabric)로 굽는다(`blender/art/prop_textures.py` 와 같은 방법 — 채도 · 색 곱): 안전모 = 칠 긁힘 + 때(노랑 그대로) · 배터리 = 칠 벗겨진 통(빨강 그대로) · 탄띠 · 수통 덮개 = 면 띠 결 · 버클 · 받침 · 뚜껑 = 닳은 쇠 · 방독면 고무 = 약한 윤 + 먼지. 색은 지금 색을 지킨다(탄띠 색만 물을 것 3).

## 구현

### 차례 1 — 굽기 · 넣기 (09-30) → 판정 ⑤ 대기
- 받음: Poly Haven denim_fabric 1K(Color · Roughness · NormalGL, 합 1.83 MB, CC0) → `build/art/cand_tex/`(ART-1 과 같은 곳).

- 부위 몫(그림 넓이): 옷 57 % · 흰 면 10 % · 장갑 16 % · 장화 14 % · 살 3 %. 거칠기 옷 0.93 · 흰 면 0.96 · 장화 0.56 · 장갑 0.65.
- **제안서와 다른 점**:
  1. 스크립트를 둘로 — Blender 파이썬에 PIL 이 없어 굽기(`player_look_bake.py`)와 짜기(`player_look.py`)를 나눔.
  2. **장화는 색이 아니라 높이(34 cm 아래)로 가름** — 장화가 짙은 회색이라 색으로는 옷과 안 갈렸다(검정 기준으로는 0.2 %). 살 · 머리카락도 따로(천 결 안 입힘).
  3. **천 결은 1 cm 아래 짜임만 남긴 첫 판이 2 m 에서 화면을 0.6 % 만 바꿨다** — 2 m 에서 한 픽셀이 약 3 mm 라 짜임은 안 보인다. 3 cm 보다 작은 잔주름까지 남기고 세기를 맞춤(평균 기울기 0.10). 무늬 한 장 = 원본 실제 크기 0.5 m.
  4. **"옷 윤이 옛보다 낮다" 검사(`player_cloth_matte`)는 뺐다** — 몸통만 재도 매끈함이 더하는 밝기가 옛 2.4 % · 새 2.5 % 로 둘 다 작았다. 머리등이 보는 사람 쪽에서 비춰 윤이 거의 안 보인다 → **짐작 ①(윤기 한 값)은 찰흙의 원인이 아니었다.** 부위별 윤기는 그대로 둔다(고무와 면이 다른 것은 맞다).
  5. 탄가루 셋 판은 몸만 — 소품은 보통 하나로 구움. 옛/새(Shift+6)도 몸만 바꾼다(소품은 늘 새 것).
  6. 판정 ⑤ 사진은 머리등만(복도) — 부스 전등 아래는 실행 파일 판정 ⑥ 에서.
