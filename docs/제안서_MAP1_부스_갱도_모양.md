# 제안서 MAP1 — 부스 갱도의 모양 (한 덩어리 회색 모형 + 괴물 길찾기)

작성 2026-09-24. 10/17 순서의 ②(사용자 결정 09-24: 조사 → 맵 모양 → 한 판 규칙 + 이름표 판·칠판 → 제출물). 바탕 = 조사 07 `docs/기획서/조사/07_갱도_평면과_모양.md`(1997 도계광업소 작업장 골격도) · 기획서 4절 구역·4-1 부스 지도(09-24 통과). 평면도 그림: `docs/그림/MAP1_평면도_초안.svg`(.png).

## 무엇을 하려는지

부스 한 판을 할 갱도를 **하나로 정해진 맵**으로 만든다. 7 m 칸에 맞추지 않고 한 덩어리로 만들어서 실제 갱도처럼 넓어졌다 좁아지고, 캐다 만 곁굴과 무너져 막힌 곳이 있게 한다. 이번 단계는 **모양만** 본다 — 벽·바닥은 지금 쓰는 바위 그림을 그대로 입히고, 갱목은 네모 막대, 소품은 자리만 잡는다(모델은 10/17 뒤, 하나씩 승인).

평면도(위에서 본 모양)는 실제 도면의 뼈대를 그대로 따른다: 곧은 운반갱에서 **비스듬히** 갈라진 크로스컷이 탄층에 닿으면, 한쪽은 탄층을 따라 **굽는 연층 + 9 m 간격의 막다른 곁굴**, 다른 쪽은 **석탄 기둥 사이 바둑판 통로 + 무너진 채굴적**이다(조사 07 — 도면에서 채굴적은 점선, "탄벽채굴적"). 기획서 4-1 지도(갈림 → 왼쪽 갱도 작은 틈 / 오른쪽 갱도 큰 틈 → 막장 둘)와 같은 틀이다.

- 케이지에서 막장 A 까지 약 44 m, 막장 B 까지 약 44 m. 갱도 길이 합은 기둥 사이 통로를 빼고 약 70 m(목표 60~80 m).
- **광맥 6곳**(왼쪽 3 · 오른쪽 3, 기둥 둘은 석탄 기둥이라 그 면에). 광맥 하나 = 광석 1개(지금 규칙: 두 번 치면 덩이가 빠짐)라서 **몫 5개를 채우려면 양쪽 갱도를 다 가야 한다.**
- 틈 자리 셋은 **빈 표시만** 둔다(큰 틈 2 = 막장 A 옆 · 채굴적 가장자리, 작은 틈 1 = 연층 남쪽 벽). 바위 틈 모양·비집기 연출은 10/17 뒤 R2 다시 하기에서.

## 어떻게 만들 것인지

### 1. 맵 그물 — Blender 스크립트 `blender/map/make_booth.py` (새로)

맨 위 표 하나(구역마다 중심선 점들 · 폭 · 높이 · 빛 구역)로 전부 만든다. 평면도를 고치면 표만 고친다.
1. 표대로 **빈 공간(공기)** 덩어리를 만든다 — 갱도는 중심선을 따라 쓸어 낸 단면(바닥 평평 · 벽 · 낮은 아치 천장), 기둥 사이는 상자에서 기둥을 뺀 것.
2. 덩어리를 합쳐 **복셀 리메시**(0.15 m)로 이음새 없는 그물 하나로 만든 뒤 면을 뒤집는다(안에서 보는 동굴). 갈림길 이음새 손질이 필요 없는 길이다.
3. 벽에 잡음 변형(±0.15 m)으로 바위 요철, 바닥은 ±0.03 m. 면 수를 줄인다(목표 20만 삼각형 이하).
4. 그림: 지금 쓰는 Poly Haven `rock_face_04`(벽) · `brown_mud_rocks_01`(바닥)를 상자 투영으로. 갱목: 네모 막대 동발(기둥 2 + 가로대) 운반갱·크로스컷·연층에 1.5 m 간격, 기둥 사이 구역은 없음(실제로 "동발 없이 긁어냄", 조사 07). 무너진 곳은 돌무더기 덩어리, 채굴적 앞은 나무 울타리 막대 + 경고판 판자.
5. 노드(코드가 이름으로 찾는다): `SHL_Booth`(보이는 그물) · `COL_Booth`(충돌, 같은 그물) · `SLOT_Pocket_1..6` · `SLOT_GapBig_1..2` · `SLOT_GapSmall_1` · `SLOT_Light_*`(켜진 전등) · `SLOT_DeadLight_*`(꺼진 전등) · `SPAWN_Player` · `SPAWN_Stalker` · `SLOT_Prop_Cart` · `SLOT_Prop_Lunchbox`.
6. 내보내기 `Assets/Tunnel/Booth/booth_map.gltf` + 위에서 본 그림 `build/check_map1/booth_top.png`(평면도와 맞는지 내가 먼저 본다).

### 2. Unity 씬 — `BuildM1.MakeBooth` (새 함수)

지금 `MakeScene`(42 m 복도)이 하는 일을 그대로 쓰되 조각 대신 `booth_map.gltf` 를 놓는다: 플레이어(`SPAWN_Player`) · 괴물(`SPAWN_Stalker`) · 광맥(`SLOT_Pocket_*`) · 켜진 전등(점광원, 따뜻한 색, 반지름 6 m) · 꺼진 전등(전구만). 새 씬 `Assets/Scenes/Booth.unity`. **인트로의 "시작"이 이 씬으로 간다.** 42 m 복도 씬은 괴물 행동 검사용으로 그대로 둔다(빌드 목록 0 인트로 · 1 복도 · 2 부스).

### 3. 괴물 길찾기 — `Stalker.cs`

지금 괴물은 곧은 복도 전용이다(목적지를 폭 ±2.2 m · 앞뒤 끝 안으로 자르고, 목적지로 곧게 걷는다). 이것을 Unity 길찾기(NavMesh, 패키지 `com.unity.ai.navigation` 이미 있음)로 바꾼다 — **한 가지 길**로, 복도 씬에도 똑같이 쓴다.
- 목적지 정하기(`SetTarget`) = 길찾기 바닥 위 가장 가까운 점으로.
- 걷기(`MoveTo`) = 길찾기가 준 꺾는 점들을 차례로 따라감. 몸은 지금처럼 CharacterController(충돌·밀림 코드 그대로).
- 배회 자리(`RandomNear`) = 길찾기 바닥 위 무작위 점.
- 달아나기: 벽 타고 사라지는 높이를 고정 4.4 m 에서 **그 자리 천장 높이**(위로 쏜 광선)로. 달아날 자리(램프 원뿔 안 8~14 m)도 길찾기 바닥 위로.
- 씬을 만들 때 길찾기 바닥을 굽는다(NavMeshSurface, 괴물 반지름 0.6 m).

### 4. 괴물 키와 천장 — 재 보고 맞춘다

실제 갱도는 높이 2.4~2.7 m 인데 괴물 충돌 캡슐은 2.8 m 다(지금 복도는 높이 4.4 m 라 문제가 없었다). 먼저 게임 안에서 동작마다(걷기 · 조깅 · 달리기 · 서서 둘러보기 · 더듬기) **머리 꼭대기 높이**를 잰다. 천장보다 높은 동작이 있으면 캡슐을 2.2 m 로 줄이고, 천장이 낮은 곳에서는 몸을 더 숙이게 한다(숙임은 이미 `StalkerAnim` 에 있는 값을 더 준다). 실제 크기를 지키면 괴물이 갱도를 꽉 채워 **더 크고 가깝게** 보인다 — 기획의 "크고 힘센 것이 덮친다"와 맞는다(물음 3).

### 5. 판정 도우미 (실행 파일)

- 켜진 전등 밝기를 **−/+ 키**로 바꾸고 값을 화면 구석에 보인다(판정 뒤 받은 숫자를 `Tuning` 에). 숫자패드도.
- 괴물 행동 끄기·내 앞에 세우기 키(지금 DevHud 0·9·U)는 부스 씬에서도 된다.

## 덮어쓰기·지우기 (승인 전 확인)

- **지워지는 것 없음.** 42 m 복도 씬·조각·검사 132 개는 그대로 남는다.
- 바뀌는 것 둘: ① 인트로 "시작"이 복도 대신 부스 맵으로 간다(복도는 검사로만 돈다) ② 괴물 걷기가 곧게 걷기에서 길찾기로 바뀐다 — 복도에서도. 옛 걷기 코드는 지운다(git 에 남는다).

## 만드는 차례

1. **평면도 승인**(이 문서의 그림) — 여기서 모양을 고치면 표만 고친다.
2. Blender `make_booth.py` → 위에서 본 그림 + 1인칭 시점 캡처 몇 장을 **먼저 보여 준다**(그물만, Unity 전).
3. Unity: 길찾기 괴물 → 복도 132 개 PASS 확인 → `MakeBooth` → `-only booth` PASS + 사보타주 FAIL 확인 → 전체 `build.sh` → 커밋 → **사용자 F5 판정**.

## 확인 목록 (F5)

- [ ] 케이지에서 걸어 들어가며 실제 갱도처럼 읽힌다 — 넓은 정거장 → 운반갱 → 좁아지는 크로스컷 → 굽는 연층 · 막다른 곁굴 · 기둥 사이 · 무너져 막힌 곳
- [ ] 4분 한 판에 알맞은 크기다(길을 잃지 않되, 되돌아가는 길이 멀게 느껴진다)
- [ ] 괴물이 맵 어디든 따라오고, 기둥을 돌아 따돌릴 수 있다
- [ ] 켜진 전등 → 꺼진 전등 → 어둠의 순서가 무섭게 읽힌다(밝기는 −/+ 키로 정해 준다)

## 물어볼 것

1. **평면도**(그림) 이대로 가나, 고칠 곳이 있나 — 길이·갈림·막장 자리·채굴적 자리.
2. 오른쪽 **기둥 사이를 돌아 도망치기** — 넣나(추천: 넣는다. 곡괭이 말고 몸으로 따돌리는 길이 생기고, 실제 바둑판 채굴 모양이다).
3. **실제 크기**(천장 2.2~2.7 m)를 지키고 괴물이 숙여 다니게 할까(추천), 아니면 갱도를 괴물에 맞춰 높일까(높이 3 m 넘게 — 실제보다 크다).
4. 인트로 "시작"을 부스 맵으로 바꾸는 것 괜찮나(42 m 복도는 검사용으로만 남는다).
