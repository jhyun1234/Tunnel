# 제안서 3D-②b — 점토 같은 살에 질감을 넣고, 눈 구체를 없애고 눈구멍 자체가 빛나게 한다

작성 2026-09-17. 출처: 3D-② 1차 판정(`docs/HANDOFF.md` 4절, 09-17) — 지직거림 없어짐(통과), 뼈 밝기 통과, 그림자 통과. 불통과 둘: **"점토 느낌이 너무 난다, 질감을 추가하고 싶다"** · **"눈이라는 구체 두 개가 너무 잘 보인다, 이질감 그대로"**.

## 문제 1. 살이 점토 같다 — 왜
세 가지가 겹쳤다.
1. TRELLIS 가 만든 몸 자체가 매끈하다(AI 가 뽑은 형태는 큰 덩어리만 있고 잔 요철이 없다). 3D-①에서 구운 노멀맵은 "원본 28만 면 → 게임 몸 12만 면" 차이만 담아서 거의 평평하다(섬 안 기울기 평균 0.08, 화면 차이 0.0007).
2. 거칠기가 온몸 1.0 상수다 — 젖은 근육도, 마른 뼈도, 회청색 살도 똑같이 무광이라 재질 구분이 없다. 이게 점토 느낌의 큰 몫이다.
3. 색 그림에는 근육 결·핏줄·뼈 이음이 그려져 있는데 요철로 서 있지 않다.

## 고치는 법 1 — Blender `stage12` 에서 그림 두 장을 더 굽는다 (Godot 파일은 안 건드린다)
- **요철 그림 강화**: 노멀맵 = 지금 구운 것 ⊕ **색 그림에서 뽑은 요철**(밝기 → 높이 → 노멀, stage6 의 `normal_from_height` 재사용 — 그려진 근육 결·핏줄·뼈 이음이 그대로 요철로 선다) ⊕ **잔결**(살에만, 2~4 mm 노이즈). 세 장을 탄젠트 공간에서 합친다. 자기 검사: 섬 안 기울기 평균 0.08 → **≥ 0.15**.
- **거칠기 그림**(glTF `metallicRoughnessTexture`, G 채널): 색으로 나눈다 — 붉은 근육·검은 구멍 = 젖음(거칠기 **0.5**), 회청색 살 = **0.85**, 흰 뼈 = **0.9**. 금속 0 그대로. 램프 흰 점은 기존 "탄 픽셀 ≤ 3 %" 검사가 잡는다.
- **세기는 사용자가 실행 파일에서 찾는다**(판정값 규칙): DevHud 켠 뒤 **7/8 키 = 요철 세기**(`normalTexture_scale` 0.25 배씩, 시작 1.0) · **, / . 키 = 거칠기 배율**(`roughnessFactor` 0.9 배씩, 시작 1.0). 화면에 값이 뜬다. 받은 값을 `Tuning.STALKER_SKIN_NORMAL_SCALE`·`STALKER_SKIN_ROUGH_MUL` 에 적는다. 값을 넣는 곳은 새 부품 `StalkerLook.cs`(모델 밑, 시작할 때 살·머리 재질에 세기·거칠기·발광을 넣는다 — `Stalker.cs` 는 안 건드린다).
- 검사 `-only monster`: ⑧ `monster_skin_has_relief` — 2 m 정면 몸 영역 구조값(이웃 밝기 차) 지금 24.6 → **≥ 30**(제안값, 실측으로 조정). 사보타주 `flatskin`(요철 그림 뺌)이 이걸로도 FAIL.

## 문제 2. 눈 — 구체가 보인다
크기를 줄이고 안으로 넣어도 "구체 두 개"로 읽힌다. 구체를 **없앤다**.

## 고치는 법 2 — 눈구멍 면 자체가 빛난다
- Blender `stage12` 에서 머리 그림에 **발광 그림**(glTF `emissiveTexture`)을 하나 더 굽는다: 눈구멍 자리만 흰 얼룩, 나머지 검정. 자리는 3D-② 눈 위치 계산과 같은 식(머리 상자 앞면 85 %·가운데−20 %·좌우 ±40 %)으로 점을 잡고, 그 점에서 **3.5 cm** 안 면들의 UV 에 칠한다(눈구멍이 얕은 홈이라 그 홈 면이 칠해진다).
- 발광 색 = `STALKER_EYE_COLOR`, 세기 `STALKER_EYE_EMISSION` 시작 **0.6**(지금 구체 Unlit 0.6 과 같음) — **k / l 키**로 0.8 배씩 조절. 램프 아래에서는 빛에 묻혀 그늘진 눈구멍이고, 어둠·먼 곳에서는 두 점으로 남는다.
- 눈 구체 `EyeL`·`EyeR` 삭제. `Stalker.cs` 의 눈 높이(시선 레이 2.4 m)는 그대로.
- 검사 바꿈: `stalker_eyes_glow_in_dark`(M4) 영역을 눈 구체 → **머리 메시** 화면 사각형으로, 문턱은 실측 뒤(영역이 커져 평균이 내려간다). 사보타주 `dimeyes` = 발광 0 → FAIL.
- 캡처: `13_monster_2m_face`(램프 켬) · **`13_monster_2m_face_dark`(램프 끔, 새로)** · `13_monster_at_14m`.
