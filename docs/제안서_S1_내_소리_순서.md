# 제안서 S1 — 내 소리 순서 (발소리 3자세 + 착지음, 42 m 복도)

작성 2026-09-16. 출처: `docs/design/sound_design.md` Step 2(사다리 0.05 → 0.1 → 0.2 → 0.4 → 0.8) · Step 7 S1. Godot 원본 `new-game/scripts/Tuning.gd` STANCE 표 · `Player.gd:343~348`(발소리 소음). 재미 문장의 앞 절 **"소리를 내야"** — 지금은 곡괭이 소리만 있고 발소리는 화면 원(20 m·25 m)뿐이다. M6 판정 5번(착지 소리)을 여기서 끝낸다.

## 무엇을 하려는지
숙이기·걷기·달리기 발소리가 나고, 빨라질수록 확실히 커진다(이웃끼리 2배 = 6 dB). 던진 곡괭이는 떨어진 자리에서 낮은 '쾅'(타격음보다 작게). 곡괭이 타격은 지금 그대로 꼭대기. 그리고 **발소리가 괴물 귀에도 들어간다** — 지금 Unity 괴물은 곡괭이·착지만 듣고 발소리는 못 듣는다(Godot 는 들었다). 눈 감고 "숙이기·걷기·달리기·던지기·곡괭이" 5가지를 소리만으로 가르는 것이 목표.

## 어떻게 만들 것인지
- **발소리 발신** (`Player.cs`): Godot 그대로 — 땅에 닿아 움직이는 동안 `stepLeft` 가 0 이 될 때마다 `NoiseBus.Make(위치, 자세별 반경, "step", player)`, 멈추면 0(다시 걸으면 바로 한 걸음). 반경·간격은 Godot STANCE 표(숙이기 2 m · 1.2 s / 걷기 6 m · 0.5 s / 달리기 14 m · 0.32 s).
- **소리 재생기** (`NoiseSound.cs`, 새 파일): `NoiseBus.Made` 를 듣고 종류 → 파일·음량 표 한 장으로 튼다. `step` = 2D(머리 안, spatialBlend 0), 반경 2/6/14 → 음량 0.05/0.1/0.2, 발걸음 4변주 중 직전과 다른 것. `pick_land` = 착지 자리 3D, 타격음 파일에 pitch 0.6 · 음량 0.4 (가공 파일 없이 재생 때 pitch — 파일 0개). `pick` 은 지금 `MiningFx.HitSound`(M2 판정 통과, 맞은 자리 3D · 0.8) 그대로 두고 표에는 안 넣는다. `ThrownPick` 의 지금 착지음(타격음 1.0 · pitch 0.8) 호출은 지운다.
- **파일**: `Assets/Audio/Player/footstep_concrete_000~003.ogg` + 같은 라이선스 파일 (Kenney Impact Sounds CC0 — 받은 zip 이 PC 에 없어 kenney.nl 에서 다시 받는다, 약 2 MB. zip 에 footstep 이 없으면 멈추고 묻는다). LFS.
- **씬** (`BuildM1.MakeScene -force`): 발걸음 클립 4개를 `NoiseSound` 에 배선.
- **검사** `-only sound`: ① 숙이기·걷기·달리기 각 2 s 이동 → 발소리 RMS 최대값이 순서대로 커지고 이웃 ≥ 2.0배 ② 발 앞에 던져 착지(2 m 안 = 최대 음량) RMS > 달리기 × 2, 곡괭이 타격 RMS > 착지 × 2 (기존 `mining` 구간 값 재사용) ③ 4변주가 같은 파일 연속 2번 없음 ④ 램프 끄고 배회 괴물 12 m 에서 달리기 → 2 s 안 Investigate, 8 m 에서 걷기·3 m 에서 숙이기 → 배회 그대로. 사보타주: `flatsteps`(음량 전부 0.2 → ①) · `quietfeet`(발소리 반경 0 → ④) · 기존 `mute` 여전히 FAIL.
- **Mixer(그룹 4·울림·Dark 스냅샷)는 이번에 안 만든다** — 에디터 API 로 `.mixer` 를 코드가 못 만들고, S1 검사 4개 중 필요한 것이 없다. 첫 필요(램프 끄면 크게, 울림 꼬리)가 오는 S4 에서 한 번에. 폴더는 설계서 이름(Player)으로 시작한다.

- [ ] 숙이기·걷기·달리기 발소리가 나고, 자세를 바꾸면 0.5 s 안에 소리가 바뀐다
- [ ] 같은 발소리가 연달아 두 번 안 난다
- [ ] 곡괭이를 던지면 떨어진 쪽에서(왼쪽으로 던지면 왼쪽) 낮은 소리, 곡괭이 타격보다 작다
- [ ] 램프 끄고 괴물 근처(12 m 안)에서 달리면 온다, 걸으면(6 m 밖) 안 온다

## 물어볼 것 (판정 때)
1. 눈 감고 다른 사람 조작을 듣고 5가지(숙이기·걷기·달리기·던지기·곡괭이)를 5/5 맞히는가 — 못 맞히는 짝이 어느 것인가
2. 숙이기 발소리 1.2 s 간격(Godot)이 "조용히 걷는다"로 읽히는가, 끊긴 느낌인가
3. 착지음 pitch 0.6 이 "곡괭이가 떨어졌다"로 들리는가, 다른 물건 소리로 들리는가 (M6 5번)
4. 발소리가 2D(머리 안)라 어색한가
