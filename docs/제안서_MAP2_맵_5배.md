# 제안서 MAP2 — 한 층 맵을 약 5배로 (굴을 늘리고 폭도 넓게 · 부스는 일부만 연다)

작성 2026-09-24. MAP1 판정(09-24)에서 나온 것: "넓다고 느껴지지 않는다 · 네 명이 흩어지려면 5배는 넓어야 한다 · 부스용으로 막을 곳 없음 · 따돌릴 수 있지만 좁아서 쉽지 않다 · 전등 밝기 60.5". 이어서 물음 셋의 답: **둘 다(굴을 늘리고 폭도 넓힘) · 부스는 일부만 · 한 판 규칙보다 맵 먼저**.
평면도 그림: `docs/그림/MAP2_평면도_초안.png` (그린 스크립트 `blender/map/map2_plan.py` 의 표가 이 문서의 구역·수치다 — 승인되면 그 표를 `make_booth.py` 에 그대로 넣는다).

## 무엇을 하려는지

지금 맵(MAP1)은 굴을 다 이어도 약 210 m 이고, 괴물이 걸을 수 있는 바닥이 **432 m²**(Unity 가 잰 값)다. 이것을 **약 5.8배(약 2,500 m²)** 로 키운다. 같은 방법(굴 폭에서 괴물 몸 반지름 0.6 m 씩 빼고 칸을 세기)으로 MAP1 을 재면 430 m² 로 Unity 값과 맞았으니, 이 숫자는 믿을 만하다.

뼈대는 MAP1 과 같은 실제 층 모양(조사 07: 운반갱 하나 · 크로스컷 여럿 · 탄층을 따라가는 연층)이고, 더 크게, 더 여러 갈래로 만든다. 실제 탄광도 한 갱이 150~2,800 m 이고, 도면에 "갱구로부터 2990 M" 이라고 적힌 크로스컷이 있다(조사 07). 1 km 짜리 한 층은 실제보다 크지 않다.

- 켜진 전등 8개(밝기 **60.5**, 사용자 09-24) · 꺼진 전등 10개. 괴물은 지금처럼 하나, 채굴적에서 시작.

**부스판(혼자 약 5분)**: 막힘 스위치 **6곳**. 제안 = 1·2·3 켬(운반갱 104 m · 연층 104 m · 바람길 입구) → 동쪽 절반(크로스컷 4~6 · 노보리 · 막장 B)과 바람길·펌프실이 닫힌다. 열린 곳 약 620 m · 바닥 약 1,400 m²(MAP1 의 3.2배), 광맥 약 20곳. 몇 개를 켤지는 MAP1 처럼 실행 파일에서 키로 걸어 보고 정한다(4·5·6 은 더 줄이고 싶을 때: 크로스컷 3 · 채탄장 · 기둥 사이 두 번째 입구).

## 어떻게 만들 것인지

MAP1 에서 만든 길을 그대로 쓴다 — **맵은 표 하나로 만들어진다**(`make_booth.py`). 새로 짜는 코드는 적고, 대부분 표를 바꾸는 일이다.

### 1. 맵 그물 — `blender/map/make_booth.py`
1. 맨 위 표(`TUNNELS` · `ROOMS` · 자리들)를 이 제안서의 표로 바꾼다.
2. **비탈 중간의 갈림**: 채탄장 오르막 중간에서 곁굴이 갈라진다. 갈림 자리는 오르막에 평평한 받침(2.6 m)을 넣는다(MAP1 에서 비탈 끝에 받침을 넣던 규칙을 중간 갈림까지 넓힌다) — 받침이 없으면 곁굴 입구에 턱이 생긴다. 자기 검사(바닥 ±0.2 m)가 잡는다.
3. **면 수**: 지금 29만 삼각형(210 m). 그대로 5배면 약 145만 → 복셀 0.15 → 0.2 m 로 키워 약 80만을 목표로, 한도 50만 → 120만. 덩어리 5 → 약 12(40 m 칸마다) — 안 보이는 덩어리를 그리지 않게. fps 는 검사로 잰다(지금 194~268, 기준 60). 모자라면 그때 Unity 가림 굽기(occlusion)를 제안한다.
4. **입구 자리를 맵이 알려 준다**: 굴 입구마다 `SLOT_Mouth_*`(선 자리 + 들어갈 방향)를 내보낸다. 지금은 검사 코드에 입구 10곳 좌표를 손으로 적었다 — 맵이 바뀔 때마다 두 군데를 고치지 않게 한다.
5. 막힘 돌무더기 `BLK_1..6`, 광맥 `SLOT_Pocket_1..30`, 틈 · 전등 자리는 지금 이름 그대로.

### 2. Unity — `BuildM1.MakeBooth` · `Tuning` · `DevHud`
- `MakeBooth` 는 그대로(자리 이름으로 찾는다). 길찾기 바닥이 커질 뿐.
- `Tuning.BOOTH_BLOCKS` 6칸(제안 기본값 1·2·3 켬). `DevHud` 막힘 키 F5~F8 → **F5~F10**.

### 3. 괴물
- 길찾기는 MAP1 그대로. 넓은 맵에서 괴물이 플레이어를 만나는 빈도(배회 범위)는 **판정 때 숫자로 본다** — 지금 값으로 시작하고, 너무 안 만나면 그때 고친다.
- 괴물도 플레이어와 같은 "비탈에서 떴다 붙었다" 방식(바닥 붙이기 −1 m/s)이다. 노보리·오르막이 늘어나므로, 괴물이 비탈을 내려갈 때 뜨는지 검사로 재고, 뜨면 플레이어와 같은 방법으로 고친다.

## 검사 (배포 실행 파일, `-only booth` — 빠른 검사 `bash tools/quick.sh booth`)

지금 부스 검사 12개를 새 맵에 맞게 고친다. **걸어서 도는 길을 줄여** 검사 시간이 크게 늘지 않게 한다(지금 2분 25초 → 약 4분 목표).

| 검사 | 통과 조건 | 사보타주 |
|---|---|---|
| `booth_size` (새로) | 길찾기 바닥 넓이 ≥ 1,950 m² (MAP1 432 의 4.5배) · 부스판(1·2·3 켬) ≥ 1,100 m² | `smallmap`(표를 MAP1 로) |
| `booth_walk_route` | 봇이 W 로 걸어서 케이지 → 막장 A · C · B → 케이지 (광맥 30곳 전부는 걷지 않고 **길이 있는지**만 잰다) | `blockcut` |
| `booth_enter_tunnels` | `SLOT_Mouth_*` 입구마다 곧장 3 m 이상 들어간다 | 입구 하나에 벽 |
| `booth_blocks` | 스위치 6곳 각각 켜면 못 지나감 · 넷 켜도 광맥 10곳 이상 | `blockleak` |
| `booth_loop` | 고리 다섯 · 바람길 고리 · 노보리 위아래 고리가 이어져 있음 · 기둥 하나 한 바퀴 < 36 m | 기둥 사이 막기 |
| `booth_clearance` · `booth_sealed` | 폭 ≥ 2.2 · 천장 ≥ 2.5 · 구멍 없음 | `narrow` · `holeroof` |

| `booth_slope_steps` | 노보리 25° · 채탄장 15° 오르내리기 발소리 고르게 | `nosnap` |

## 안 하는 것

협동(네트워크 · 여러 명 쫓는 괴물) · 한 판 규칙(몫 · 사이렌 · 5분 끝 — 이 맵 다음 차례) · 바위 틈 모양 · 물 · 레일 · 모델 입히기 · 바람 문 너머.

## 덮어쓰기·지우기 (승인 전 확인)

- **바뀌는 것**: 부스 맵이 MAP1 → MAP2 로 바뀐다(`booth_map.gltf` · `Booth.unity` 다시 만듦). `make_booth.py` 의 MAP1 표와, 검사 코드에 손으로 적은 MAP1 숫자(막장까지 49 · 73 · 54 m, 입구 10곳 좌표, 노보리 좌표, 기둥 한 바퀴 16 m)가 새 값으로 바뀐다. **MAP1 은 git 에 남는다**(커밋 `244a8b9`).
- **그대로**: 42 m 복도 씬 · 조각 · 복도 검사 132개 · 인트로.

## 만드는 차례

1. **평면도 승인**(이 문서 그림) — 고칠 곳은 표만 고친다.
2. Blender 로 맵 그물 → 위에서 본 그림 + 1인칭 캡처를 **먼저 보여 준다**(Unity 전).
3. Unity: `MakeBooth -force` → `quick.sh booth` PASS · 사보타주 FAIL → 전체 `build.sh` → 커밋 → **사용자 판정**(막힘 스위치 F5~F10 으로 부스판 범위).

## 확인 목록 (판정)

- [ ] 넓다고 느껴진다 — 네 명이 흩어질 만하다
- [ ] 따돌리기가 전보다 쉽다(고리 · 넓은 굴) — 그래도 긴장은 남는다
- [ ] 부스판: 스위치 몇 개를 켜야 혼자 5분에 알맞은가
- [ ] 괴물이 넓은 맵에서도 너무 드물게 오지 않는다
- [ ] 걸어서 도는 시간이 지루하지 않다

## 물어볼 것

1. **평면도**(그림) 이대로 가나, 고칠 곳이 있나 — 구역 셋(채탄장 · 기둥 사이 · 노보리) + 바람길 + 충전실 · 컴프레서실 · 펌프실.
2. **광맥 30곳** 괜찮나 (부스판에서 열리는 것은 약 20곳).
3. **부스판 기본값** 1·2·3 켬(동쪽 절반 · 바람길 닫힘)으로 시작하고 판정 때 키로 정하는 것 괜찮나.
4. 부스 맵을 MAP1 에서 MAP2 로 **바꾸는 것**(MAP1 은 git 에만 남음) 괜찮나.
