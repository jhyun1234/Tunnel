# 제안서 m3-② — 목을 늘이면 속 근육 관이 드러나게 (새 몸의 목 피부를 위·아래로 가른다)

작성 2026-09-20 (`m2-body` 가지). HANDOFF 0절 "다음 일 ②". 사용자 3차 판정(09-20) 캡처 "목 늘린 모습이 회색 각기둥처럼 밋밋"의 뒤처리.

## 한 줄
새 머리·몸의 목 살을 **머리 쪽 / 몸 쪽으로 딱 갈라**(지금은 8 cm 에 걸쳐 섞여 있어 고무처럼 늘어난다), 그 사이로 옛 몸에서 쓰던 **속 근육 관(`Miner_Neck`)이 나오게** 한다. 관은 새 목 굵기에 맞추고, 관 그림은 새 몸 살에서 다시 뽑는다. Unity 코드(`StalkerAnim.NeckOut`)는 안 고친다.

## 지금 모델에서 확인한 것 (09-20, stage18 blend 읽기만)
그림 `build/check_m3/10_neck_now_{00,15,30}cm_{side,front}.png` = 지금 · `11_neck_proto_*` = 가르기 시험(저장 안 함).
- 목 살은 거의 다 `Miner_Head` 그물에 있다(높이 2.00~2.10 m, 반지름 3.5~6 cm). 점 2,798개가 머리 뼈 ↔ 목·가슴 뼈에 **섞여** 붙어 있다 → 머리 뼈를 밀면 그 사이 면이 널빤지처럼 늘어난다(사용자가 본 "회색 각기둥"). `10_neck_now_15cm_side.png` 에서 그대로 보인다.
- 속 근육 관 `Miner_Neck` 은 `m2_body.py` 가 축 둘레 **0.15배**로 줄여 놓았다(반지름 0.7 cm — 새 목이 옛 목보다 가늘어 관이 삐져나와서). 그래서 목을 빼도 보일 것이 없다. 옛 관 반지름은 4.3~5.5 cm, 새 목은 3.5~6 cm.
- 가르기 시험: 머리 뼈 무게 ≥ 0.5 인 점은 머리 100 %, 나머지는 머리 0 % 로 → 머리가 몸에서 깨끗이 떨어진다(`11_neck_proto_15cm_side.png`). 두 쪽에 걸친 면은 머리 403 · 몸 62 · 안감 62 · 속 몸통 19개. 시험에서는 이 면을 지웠더니 **안 뺐을 때도 목에 틈**이 보였다(`11_neck_proto_00cm_side.png`) → 지우면 안 된다.
- Blender 시험으로는 관이 나오는 모습을 못 본다 — 관 마디 뼈 7개는 Unity(`NeckOut`)가 놓는다. 관이 실제로 어떻게 보이는지는 **배포물 캡처로만** 확인된다.

## 하는 일 (새 스크립트 `blender/rig/m3_neck.py`: stage18 → `miner_v5_stage19_m3_neck.blend`, 입력은 안 고친다)
1. **가르기**: 네 그물(머리·몸·안감·속 몸통)의 점을 머리 쪽 / 몸 쪽 한 곳으로. 걸친 면은 M1e 때처럼 **지우지 않고** 머리 쪽 점을 복사해 몸 쪽에 붙인다 → 쉬는 모양 그대로, 목 나오는 곳의 살 옷깃이 된다.
2. **관 굵기**: `m2_body.py` 의 0.15배를 되돌리고, 새 목 속에 다 들어가는 **가장 큰 배율**을 스크립트가 찾는다(0.05 간격, "쉬는 자세에서 목 살 밖으로 나온 관 점 0개"를 만족하는 최대). 예상 0.6~0.7배(반지름 약 3 cm).
3. **관 그림**: 지금 관 그림은 옛 몸(TRELLIS) 살에서 뽑은 것이라 새 살과 색·결이 다르다. `add_long_neck.py` 의 `SkinSampler`(3D 자리의 살 색·요철 뽑기)로 **새 몸통·새 머리 살에서 다시** 뽑는다(꼭대기 12 cm = 머리 턱·볼 살, 아래 = 몸통 살 — M1e 4차 판정에서 통과한 방식 그대로).
4. `tools/bake_m3.sh` 에 단계 추가(`m3_fingers.py` → `m3_neck.py` → `walk_knuckle.py`).

옛 몸에 있던 "살 소매(턱 밑 찢긴 살 자락)·머리 밑 마개"는 `Miner_Neck` 그물 안에 이미 있다 — 굵기만 맞추면 따라온다. 새로 만들지 않는다.

## 검사 (`m3_neck.py` 자기 검사)
1. 네 그물 모두: 머리 뼈 무게가 0.01~0.99 인 점 **0개**(섞인 점 없음).
2. 머리 뼈를 30 cm 밀었을 때 가장 많이 늘어난 변 ≤ +1.5 cm(손가락 때와 같은 잣대 — 지금은 +30 cm).
3. 쉬는 자세에서 모든 살 점이 가르기 전과 같은 자리(차 < 0.1 mm) · 면 수는 그대로거나 늘기만(지운 면 0).
4. 쉬는 자세에서 목 살 밖으로 나온 관 점 0개(여섯 방향 광선 — M1e 방식) · 관 배율 ≥ 0.4(너무 가늘면 FAIL — 실 같은 목은 의미 없다).
5. 관 그림: 못 찾은 픽셀 ≤ 10 % · 관 평균 색과 새 몸통 목 둘레 살 평균 색 차 ≤ 0.08.
- **사보타주**: `SABOTAGE=blend`(가르기 안 함) → 1·2 FAIL · `delstraddle`(걸친 면 지움) → 3 FAIL · `TUBE=1.0`(옛 굵기) → 4 FAIL · `oldtex`(그림 안 바꿈) → 5 FAIL.
- **배포물**: `tools/build.sh -only monster` 에 새 FAIL 없음 + 목 캡처. 기존 `anim_neck_*` 검사는 `-only anim` 에서 같이 본다(숫자 기록).

## 모름
- 관이 새 목 속에 다 들어가는 배율이 실제로 얼마인지(찾아 봐야 안다). 0.4 미만이면 멈추고 묻는다 — 그때 안: 목 살(머리 쪽 소매)을 조금 넓힌다.
- 새 머리의 목 살 아래 끝(가른 자리)이 목을 뺐을 때 **들쭉날쭉한 자락**으로 보일 텐데(시험 그림의 턱 밑 자락), 그것이 "찢긴 살"로 좋게 읽히는지 지저분한지 — 판정 몫.
- 갸웃 110° 때 새 머리가 새 어깨에 파고드는지(옛 몸에서는 25 cm 저절로 빼서 0 이었다) — 새 몸으로는 안 쟀다. 이번에 같은 셈으로 재서 숫자만 낸다.
