# MAP4 판정 — 아직 답을 못 받은 물음

68차부터 세 번 물었는데 답을 못 받은 것들이다(판정 ① · ② · ③). 여기 한 곳에만 적는다. 답을 받으면 그 줄에 날짜와 답을 적고, 끝난 물음은 "받은 답" 절로 옮긴다.

실행 파일: `cd C:\Users\anjyo\Tunnel\unity; .\build\Tunnel\Tunnel.exe -map4` → 인트로 → 시작.
값은 화면 왼쪽 아래 석 줄에 뜬다. 값을 저장하는 키는 없으니, 맞춘 값이 있으면 화면의 숫자를 읽어 알려 준다.
`[ ]` 로 볼 자리 100곳을 오간다. 화면 아래 `spot 번호/100 이름` 에서 이름을 보고 찾는다.

## 키 (숫자패드 안 씀, Shift 를 누르고 있으면 안 먹음)

| 키 | 하는 일 |
|---|---|
| T | 벽 · 바닥 사진을 곳마다 다르게 / 끄면 전부 같은 사진 |
| G | 사진 대신 번호 색으로 보기 |
| Tab | 어둡기를 바꿀 사진 번호 고르기 (벽 / 바닥) |
| 5 6 | 고른 사진 어둡기 ∓0.05 |
| 7 8 | 이음 길이(한 사진이 다른 사진으로 바뀌는 거리) ∓1 m |
| − = | 얼룩 정도 ∓0.1 (0 = 뿌옇게 겹침, 1 = 얼룩처럼 번짐) |
| ← → | 바위 전체 밝기 |
| Home End | 젖음 ∓0.25 |
| 1 2 | 전등 세기 ∓4 |
| 3 4 | 전등이 닿는 거리 ∓1 m |
| 9 0 | 은은한 빛(그늘을 채우는 옅은 빛) ∓0.02 |
| B | 전부 처음 값으로 |
