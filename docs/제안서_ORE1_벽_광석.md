# 제안서 ORE-1 — 벽에 박힌 광석: 둥근 덩이를 실제 막장처럼

main, 2026-09-27. **승인(09-27): 광석 = 석탄 · 띠 비스듬 30° · 결 후보 둘(한국식·네모식)을 그림으로 → 차례 1 → 판정 ① "둘 다 넣는다" → 차례 2~3 끝, 실행 파일 판정 ② 대기.** 조사 = `docs/기획서/조사/12_막장_광맥_레퍼런스.md` · 한 장 그림 `build/refs/ore/ORE1_레퍼런스.png`(기록 사진·게임 화면이 들어가 커밋 안 함, 만드는 코드 `docs/그림/ORE1_레퍼런스.py`).

**왜** — 사용자(09-27, ART-1 차례 2 도중): "광물이 벽에 박혀 있는 부분도 정말 현실적으로 · 워독스의 재질과 느낌을 넣어서". 사용자 순서 "캐기 한 벌"(ART-1 → **ORE-1** → 3D-P + PICK-1 → MINE-1 → SND-P → REP-2~5)의 둘째. PICK-1(곡괭이)과 MINE-1(누르고 있기 캐기)은 옆 가지에서 먼저 끝나 main 에 합쳤다(`d48dc54`, MINE-1 은 실행 파일 판정 대기).

**하나씩 낸다.** 이번 ORE-1 = 광석 자리 하나의 **모양·색·빛**(벽에 붙은 모습 + 빠져 굴러 나온 덩이). 번호만: **ORE-2** 광석 자리를 막장 끝으로 모으기 · 높이 섞기(아래 "이번에 안 하는 것").

## 1. 조사에서 나온 것 (5줄)

1. **벽에 둥근 덩이가 박힌 모습은 한 번도 없었다** — 한국 0/29 · 해외 탄층 0/18 · 금속 광맥 벽 0/14. 같은 방식은 게임 하나(Mining Simulator 2023)뿐. 지금 게임 광석(둥근 검은 덩이, 쇠처럼 반짝)은 사진과 맞지 않는다.
2. 탄광 막장은 **벽 한 면이 거의 다 석탄**(한국 3/3 · 해외 8/13), 위 경계는 **평평한 회색 판 돌**로 뚜렷(해외 12/18). 탄은 막장에 있고 굴진·운반 갱도 벽은 돌(한국 5/14).
3. 석탄은 **결 따라 모나게** 갈라진다 — 해외 네모(벽돌·계단) 7/18, 한국 비스듬한 평행 금 30~60°(Rk04 · Rk08). **램프 빛을 받은 깨진 면마다 반짝**(조명 받은 갱 안 10/13), 먼지 묻은 곳은 무광.
4. 떨어진 탄은 **모난 덩이 + 가루**, 대부분 5~20 cm · 큰 것 30~50 cm. 둥근 덩이 0.
5. 금속 광맥은 어두운 돌 속 **흰 석영 띠 5~30 cm + 녹 얼룩**(한국 6/7). 금·은 알갱이는 보통 빛에서 안 보임(0/7). 한국 탄전 안에서 금속 광맥이 나온다는 기록은 못 찾음.

## 4. 차례

1. **모양 먼저 (비용 0, Blender 코드)** — `blender/art/make_ore.py`: 탄층 조각 후보 둘(③ 한국식 / 네모식) + 굴러 나온 덩이. 게임과 비슷한 머리등 빛(좁은 원뿔 하나)으로 찍어 **실제 사진 넷(Rk04 · Rk08 · Rw13 · Rw14) 옆에** 한 장 비교 그림 → **판정 ①(그림)**. Meshy 는 쓰지 않는다(모양이 정해진 뒤, 필요하면 따로 물음).
2. **게임에 넣기** — 고른 모양을 glTF 로 → `BuildM1` 이 광석 자리에 놓음(`OrePath` · 굴러 나온 덩이 `fx.orePrefab`) · `make_booth.py` 가 광석 자리 둘레 벽 점에 석탄 칠을 더함(점 위치·충돌 그물은 안 바꿈, 그물 .bin md5 그대로 확인) · 반짝임 세기 판정 키 · `MakeScene` · `MakeBooth -force`.
3. **검사(배포물)** — `ore_on_coal`(광석 자리마다 둘레 1 m 벽 점의 절반 넘게 석탄 칠) · `ore_budget`(광석 삼각형 합 ≤ 6만) · 기존 `-only mine` 그대로 PASS · 사보타주 `nocoal`(칠 빼기) · `bigore`(삼각형 부풀리기) FAIL 확인 → 전체 build.sh.
4. **실행 파일 판정 ②** — 확인 목록: 머리등 빛에서 광석 자리가 **멀리서(4~6 m) 알아보이나** · 반짝임 세기(키로 찾은 숫자) · 캐는 동안 덩이가 들뜨고 빠지는 모습 · 굴러 나온 덩이 · 띠가 ART-1 벽과 어울리나.

## 5. 이번에 안 하는 것 (번호만)

- **ORE-2** 광석 자리를 막장(막다른 끝) 쪽으로 모으기 — 사진은 "탄은 막장에" 지만 자리를 옮기면 맵·도는 길·검사가 바뀐다. 광석 높이 섞기(쪼그려 캐기가 저절로 생김)도 여기서.
- 막장 둘레 소품(분필 X 표시 Rk08 · 벽에 건 램프 · 발파 구멍 Rw19) — 한 장씩만 보여서(1/14 · 1/18) 근거가 약함.
- 곡괭이질 소리(SND-P) · 손(3D-P).
