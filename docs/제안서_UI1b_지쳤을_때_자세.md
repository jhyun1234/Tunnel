# 제안서 UI-1b — 지쳤을 때 자세 (램프 끄덕임이 커지고, 탈진하면 무릎을 짚는다)

작성 2026-09-16. 출처: `docs/design/ui_ux_design.md` Step 2 표 스태미나 줄([수정 3]·[수정 4]) · Step 6(DevHud 5·6 키) · Step 7 UI-1 ②. UI-1 네 가지 중 두 번째 — ① 내구도는 09-16 통과. 남은 것: ③ 화면 글자 0 · ④ DevHud 시작 시 끄기.

## 무엇을 하려는지
스태미나 숫자는 화면에 없다. 대신 **몸이 보여준다.**
- **곧(50 이하)**: 걸을 때 램프가 위아래로 끄덕이는 폭이 3배가 된다. "숨이 가빠 고개가 흔들린다." 이것 하나로만 알린다.
- **탈진(0 에서 Shift 를 계속 눌러 못 움직이는 5 초)**: 눈높이가 1.7 → 1.2 m 로 0.3 초에 내려가고 램프 원뿔이 바닥 쪽으로 20° 숙여진다 = "무릎에 손 짚고 헐떡임". 100 이 차면 0.3 초에 되돌아온다.
"소리를 내면 죽는다"의 뒷면 — 도망칠 힘이 얼마나 남았는지를 숫자 없이 몸으로 알아야 "지금 뛰어야 하나"를 정할 수 있다.

## 지금 상태와 다른 점
- Unity 에는 **램프 끄덕임이 아예 없다** (Godot `LAMP_BOB` 을 안 옮겼다). Godot 값 0.01° 는 14 m 벽에서 2 mm 라 있어도 안 보이는 값이었다. 설계서 제안값 0.03°(3배)도 마찬가지. 그래서 **끄덕임을 새로 넣고, 폭은 사용자가 실행 파일 안에서 키로 찾는다**(아래 정할 수치).
- 탈진(`Player.exhausted`)은 이미 있다 — 못 움직이고, 시점·숙이기는 된다, 100 차면 풀린다. 자세만 없다.

## 어떻게 만들 것인지
- **끄덕임** (`Headlamp.cs`): 램프 회전에 X 축(위아래) 흔들림 `sin(Player.gait) × LAMP_BOB_DEG × (속도 ÷ 걷기 속도)` 를 더한다. 위상은 발소리·곡괭이와 같은 `Player.gait` — 발이 땅에 닿는 순간 램프가 맨 아래. 서면 0. 스태미나 ≤ STAMINA_SOON 50 이면 폭 × LAMP_BOB_SOON_MUL 3(바로 바뀐다 — "갑자기 심해진다"가 신호). Headlamp 는 카메라 부모에서 `Player` 를 찾는다(씬 안 바꿈).
- **탈진 자세** (`Player.cs`·`Headlamp.cs`): `exhausted` 이면 눈 목표 EXHAUST_EYE 1.2(숙이면 1.0 이 우선), 지금 숙이기와 같은 길(`UpdateCrouch`, 캡슐도 같이 줄어듦)로 EXHAUST_TIME 0.3 s 에 이동. 램프는 추가 숙임 각을 0 → EXHAUST_LAMP_DOWN_DEG 20 으로 0.3 s 에, 풀리면 0.3 s 에 되돌림.
- **DevHud**: 플레이어 줄 `stamina 100 nod x1|x3 [EXHAUSTED]`, `5` −20 · `6` +20(설계서 Step 6). **임시** `7`/`8` = LAMP_BOB_DEG ÷1.5 ×1.5 + 값 표시 — 폭을 사용자가 찾으면 값을 Tuning 에 넣고 키는 뺀다(`8` 은 나중에 괴물 정지 키).
- **검사** `-only tired`: ① 스태미나 100 에서 1 s 걸으면 램프 X 각이 카메라와 ±LAMP_BOB_DEG 안에서 흔들린다(최대 편차 = 폭 ±20 %) · 서면 편차 0 ② 40 으로 놓고 걸으면 편차 3배 ③ Shift+W 를 5.5 s 누르면 탈진 — 0.5 s 안에 눈높이 1.2 · 램프가 카메라보다 20° 아래 · 0.5 s 동안 0.3 m 안 움직임 · 캡처 `16_exhausted.png` 에서 화면 아래 절반이 위 절반보다 밝다(바닥을 비춘다) ④ 5 s 뒤 스태미나 100 · 풀림 · 0.5 s 안에 눈 1.7 · 램프 각 0. 사보타주: `flatnod`(곧 단계에도 폭 그대로 → ②) · `nostagger`(탈진해도 자세 없음 → ③④).

## 1차 판정 (09-16)
1. 끄덕임 폭 0.6 확정 ✓ 2. 3배는 "숨 가쁘다"로 안 읽힘 — 소리 몫(설계서 [수정 6] 사운드 요청) 3. 탈진이 숙이기와 헷갈리고 바닥 5 초가 없다, 시점은 돌아간다 4. 조준 방해 없음 ✓ 5. **시야 카메라 바운스로 헐떡임을** → 반영: 시야 25° 아래 + 숨 3 cm·1.5°·0.7 s, 램프 숙임 삭제, 7/8 키 삭제

## 물어볼 것 (판정 때)
1. 끄덕임 폭 — 걷기 폭은 얼마여야 "있는 줄 모르는" 정도인가, 3배는 "숨이 가쁘다"로 읽히는가 (7/8 키 숫자)
2. 숫자 없이 끄덕임만 보고 "달리기가 몇 초 남았나"를 ±2 s 안에 맞힐 수 있는가 (설계서 확인 항목)
3. 탈진 자세 — "무릎 짚고 헐떡인다"로 읽히는가, 숙이기와 헷갈리는가, 램프가 바닥을 비추는 5 초가 무서운가 답답한가
4. 끄덕임이 조준(포켓 캐기)을 방해하는가 — 램프만 흔들리고 시점은 안 흔들리는데도 거슬리는가
