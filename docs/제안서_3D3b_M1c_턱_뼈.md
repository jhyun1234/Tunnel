# 제안서 3D-③b M1c — 괴물에 턱 뼈 하나를 넣는다

작성 2026-09-19. 사용자 순서(09-19): 손가락 굽히기(통과) → **턱 뼈** → 목 뼈. 이 제안서는 턱 하나만 다룬다. 목은 턱 판정 뒤 따로 쓴다.

## 한 줄
머리에 턱 뼈 하나를 더하고, 입 아래쪽 살을 그 뼈에 잇는다. 게임은 **지금 틀고 있는 동작 이름을 보고 턱을 벌리는 각도를 정한다**(평소 조금 벌림, 포효·잡기 때 사람보다 크게). 동작 파일 15개는 고치지 않는다.

## 지금 모델에서 확인한 것 (09-19, 원본 blend 는 안 고치고 임시 복사로)
- 뼈 65개 중 턱 뼈는 없다. 머리 살(`Miner_Head`, 점 62772개 중 머리 뼈에 붙은 것 53124개)은 입이 **원래 조금 벌어진 채** 만들어져 있다. 윗니·아랫니·입 안(검붉은 속)이 따로 있다. 입 틈은 가운데 줄에서 높이 2.12~2.14 m(모델 크기 1 기준, 게임은 1.5배)이다.
- **시험**: 턱 관절 자리(귀 앞, 윗니 높이 뒤쪽)에 임시 뼈를 두고, 입꼬리 선 → 턱 관절로 오르는 면 아래 살(점 7885개)을 이어 0°·20°·40° 벌려 찍었다 → `build/check_3d3b/24_jaw_proto_0_20_40.png`.
  - 됨: 앞에서 보면 아랫니째 턱이 내려가고, 입 안 검붉은 속이 보인다. 40°에서도 볼 살이 찢어지거나 구멍이 뚫리지 않았다.
  - **문제**: 옆에서 보면 20°부터 턱 끝이 **목 가죽끈(`Strap_Neck`) 속으로 들어간다**. 이 끈은 #41에서 머리와 몸이 붙은 이음매를 가리려고 둔 것이라 그냥 치울 수 없다.
- 시험 스크립트는 저장소 밖 임시 폴더에만 있다(구현 때 새로 쓴다).

## Step 1. 레퍼런스 — 턱으로 무섭게 만드는 법
원문을 읽은 것 = [확인], 검색 요약만 본 것 = [요약], 출처 없음 = [모름].

| 사례 | 턱이 하는 일 | 근거 |
|---|---|---|
| SCP-096 | 쫓아올 때 사람보다 **4배** 크게 벌리고 비명 | [확인] scp-wiki.wikidot.com/scp-096 |
| 라스트 오브 어스 클리커 | 얼굴이 갈라져도 이빨 달린 턱만 남음, 다가와서 문다 | [요약] |
| 데드 스페이스 슬래셔 | 턱이 둘로 갈라져 좌우로 벌어짐 | [요약] |
| 암네시아 그런트 | 아래턱이 가슴까지 늘어진 채 묶여 있음 | [요약] |
| 바이오하자드 4 리제네레이터 | 쌕쌕거리는 숨소리로 먼저 알림, 천천히 다가옴 | [확인] |
| 주온 카야코 | 목이 꺾여 끄르륵 신음만 냄 | [확인] |
| 입 찢어진 여자 | 입이 귀까지 찢어짐, 가렸다가 드러냄 | [확인] |

**공통점 → 이 괴물에 넣는 것**
| 공통점 | 넣는 것 |
|---|---|
| 평소에도 입이 조금 벌어져 늘어져 있다 (그런트·리제네레이터·카야코) | 걷기·대기 때 **8°**, 1.8 s 에 한 번 ±3° 느리게 오르내림(숨) |
| 쫓거나 덮치는 순간 크게 벌린다 (096·클리커·리제네레이터) | 포효(들킴)·잡기 때 **40°**를 0.12 s 만에 확 — 사람 최대 32~39°를 넘는다 |
| 사람보다 더 벌린다 = 턱이 빠져 보인다 (096·슬래셔·그런트) | 30°를 넘으면 턱이 앞·아래로 미끄러져 나온다(최대 1.5 cm). 사람 턱도 약 20 mm 넘게 벌리면 앞으로 밀려 나온다 [확인] — 이것으로 목 끈과 부딪히는 것도 피한다 |
| 추격 중엔 계속 벌어져 있다 | 달리기 때 **20°** |
| 맞으면 힘이 빠진다 [모름 — 지어낸 것] | 곡괭이에 맞음(`hit`) 때 **25°**로 축 늘어짐 |

뼈 사실: 턱이 도는 중심 = 귓구멍 바로 앞 [확인]. 사람이 최대로 벌리면 턱이 약 32~39° 돈다 [요약]. 게임마다 몇 도·몇 초인지는 숫자 자료를 못 찾았다 → 위 각도는 **전부 제안값**이고, 판정 때 키로 바꾼다.

## Step 2. 방법 — 턱은 코드로 돌린다
- 턱을 동작 파일(클립)에 키로 굽는 방법도 있지만, 그러면 포효·잡기·걷기 등 여러 클립을 다시 구워야 하고 판정 때 값을 바꿀 수 없다.
- 그래서 **Unity 가 매 프레임 턱 각도를 정한다**(`StalkerAnim` 의 `LateUpdate`, 팔 들기와 같은 자리). 기준은 지금 틀고 있는 동작 이름이다. 그래서 행동을 끄고 `9`로 세운 뒤 `N`으로 동작을 바꿔도 턱이 따라 바뀐다.
- 기존 동작 15개에는 턱 키가 없으니 동작과 싸우지 않는다.

## Step 3. 하는 일
1. **Blender** — 새 스크립트 `blender/rig/add_jaw.py`:
   - 입력 `Documents/MineTunnel/blender/miner_v4_stage12.blend` 는 안 고친다. 출력은 새 파일 `miner_v4_stage13_jaw.blend`.
   - 뼈 `mixamorig:Jaw`(부모 = 머리 뼈)를 턱 관절 자리에 둔다. 시험 자리 (0, 0.01, 2.165) m 에서 시작해 옆 그림으로 맞춘다.
   - 입꼬리 선 아래 살을 머리 뼈에서 턱 뼈로 옮긴다. 경계 1.2 cm 는 섞는다. **점마다 머리 + 턱 무게 합은 전과 같다**.
   - 턱이 앞으로 미끄러지는 거리(`JAW_SLIDE`)를 정해 목 끈에 안 박히게 한다.
2. **`blender/anim/walk_knuckle.py`** — 입력을 새 blend 로 바꾼다. 다시 돌려 GLB 를 굽는다(뼈 66개, 클립 15개 그대로).
3. **Unity**
   - `StalkerAnim`: 동작 이름 → 목표 각도. 벌릴 때는 빠르게(0.12 s), 다물 때는 천천히(0.4 s). 평소엔 숨. 30° 넘는 만큼 앞으로 미끄러짐.
   - `DevHud`: **`H`/`J` = 포효·잡기 턱 각도 −/+ 5°**. 값은 왼쪽 위 숫자판에 뜬다. 판정 때 사용자가 찾은 숫자를 `Tuning` 에 박는다.

## Step 4. 검사
**Blender 자기 검사** (`add_jaw.py` 끝)
1. 뼈 66개, `mixamorig:Jaw` 부모 = `Head`.
2. 점마다 무게 합(머리 + 턱)이 옮기기 전과 같다(차 < 0.001). 턱 뼈에 붙은 점은 머리 살에만 있다(몸 살·끈·못 0개).
3. 0° 에서 모든 살 점 위치가 stage12 와 같다(차 < 0.1 mm) — 뼈를 넣어도 모양이 안 바뀐다.
4. 40° + 미끄러짐에서 턱 살 점이 목 끈 상자 안에 **0개**.
5. 40° 에서 턱 살과 몸 살 사이 가장 긴 변이 0° 때의 2배 이하 — 살이 길게 늘어나 찢어져 보이지 않게(제안값).

`walk_knuckle.py` 기존 검사는 전부 그대로 통과하고, 뼈 66개 + 그림 11장 바이트 일치(라이선스 절차 ④)를 확인한다.

**봇 검사** `bash tools/build.sh -only anim` (배포된 실행 파일에서)
1. 배회 중 턱 각도 5~12° · 들킴 포효 동안 최대 ≥ 35° · 잡기 동안 최대 ≥ 35° · 추격 15~25°.
2. 포효가 시작되고 0.2 s 안에 30° 를 넘는다(확 벌림).
3. 턱 뼈가 없는 GLB 면 FAIL(뼈 이름으로 찾는다).
4. fps ≥ 60.

**사보타주**
- Blender `SABOTAGE=noslide` → 검사 4(끈 속 점) FAIL.
- Unity `-sabotage shutjaw`(턱 구동 끔) → 검사 1·2 FAIL.

**캡처** (`build/check_3d3b/`, 파일로 보낸다): 실행 파일에서 `9`로 2 m 앞에 세운 얼굴을 정면·옆 두 장씩 찍는다. 대기 / 포효 최대 / 잡기 최대 → `25_jaw_{idle,roar,catch}_{front,side}_2m.png`. 7 m 에서 턱이 보이는지도 한 장 찍는다(`25_jaw_roar_7m.png`).

## 결정 변경 제안
1. **목 끈(`Strap_Neck`)을 최대 1.5 cm 내리거나 앞쪽을 얇게 해도 되는가.** 턱 미끄러짐만으로 끈과 안 부딪히면 쓰지 않는다. 끈은 #41 머리 이음매를 가리는 용도라, 고치면 이음매가 드러나지 않는지 같은 검사로 본다.

## 요청 (내 몫이 아닌 것)
- **사운드**(S2 보류 중, 순서만): 포효 때 턱이 확 벌어지는 순간 = 비명 시작. 평소 숨 1.8 s = 쌕쌕거림(리제네레이터 사례).
