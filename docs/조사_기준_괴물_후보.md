# 기준 괴물 후보 — "이렇게 움직이면 무섭다"를 먼저 정한다

작성 2026-09-19 (39차). 계기: MA 영상 후보 5개 판정 **"다 아니다"** — 까닭(사용자 고름): **움직임이 뻣뻣하다·기계 같다 + 자세·발상이 틀렸다.** 기준 괴물: "있다 + 후보 목록을 달라". 만드는 법은 **기준을 정한 뒤** 고른다.

**주의**: 아래 설명은 내가 아는 내용을 적은 것이다. 이번에 영상을 다시 확인하지 않았다 — 기억과 다르면 말해 달라. 작품 속 동작을 베끼지 않는다(데이터를 가져오지 않는다). 무엇이 무섭게 만드는지 **원리만** 가져온다.

고르신 느낌(09-19): 안 보이다 갑자기 · 크고 힘센 것이 덮친다 · 나를 지켜본다. (경련·뒤틀림은 안 고름 → 데드 스페이스·주온·사일런트 힐 간호사 쪽은 뺐다.)

## 먼저 — 내가 놓친 것

지금까지 나는 **사람 몸(두 다리로 서게 생긴 2.8 m, 팔이 무릎 밑까지)을 억지로 네 발로 기게** 만들었다. 그래서 어느 쪽에서 봐도 "기는 사람"이 되고, 정면에선 "서서 오는 사람"이 됐다. 이 몸의 생김새(큰 키 · 긴 팔 · 해골 얼굴 · 안전모)를 **거스르지 않고 쓰는** 길이 있다 — 아래 A 무리. 네 발을 고집할 이유는 09-18 제안서의 내 주장(P1)뿐이었고, 그 주장은 판정에서 세 번 떨어졌다.

## 내 생각 (고르는 건 사용자)

- "뻣뻣하다"와 "발상이 틀렸다"를 **같이** 푸는 길은 둘이다: **A(서서 온다)** — 이 몸에 맞고, 두 발은 쓸 수 있는 모션캡처가 많아 기계 티가 준다. **C2(볼 때 안 움직인다)** — 움직임을 안 보여 줘서 문제 자체를 없앤다.
- 섞을 수 있다: **A1 + C1** = 멀리서는 서서 나를 보고 있고(비추면 멈춤), 안 비출 때 걸어 다가오고, 가까우면 질주. 벽 구멍은 B1 에서.
- B 를 고르신다면 만드는 법을 바꿔야 한다(수식 → 손 키 또는 네발 동물 모션캡처). 같은 방법으로 네 번째 시도를 하지 않겠다.

## 물어볼 것

1. 떠올리신 괴물의 **이름**(목록에 없어도 된다).
2. 목록에서 가까운 것 — 하나 또는 섞어서(예: "A1 + C1 + B1 의 벽 구멍").
3. **서서 오는 것**으로 바꿔도 되는가 (09-18 부터의 "네 점 걸음"을 버린다).
