## 뺀 것
- Kenney 공식 무료 팩(Impact Sounds 26 종 · RPG Audio 등): 부스러짐 · 자갈 · 긁힘이 없다. 겹쳐 쓸 만한 것은 `impactSoft_heavy`(둔탁한 쿵) · `footstep_concrete`(거친 질감) 정도다. Kenney "Foley Sounds"(2014, readme 는 CC0)에 `stoneDrag` · `stonesHit` 이 있지만, 공식 배포처를 못 찾았다(제3자 미러뿐) → 뺐다.
- Juhani Junkala 512(8 비트) · Little Robot Sound Factory(CC-BY, 돌 소리 없음) · rawAmbience(라이선스 표기 없음) · AsakSFX(유료) · Pixabay 재업로드본은 뺐다.
- 확인 필요: NPS Rockfall(공공 저작물, 표기 부탁, 녹음 장소가 갈림) · Internet Archive SSE ROCKS(CC0 표기의 근거 없음).
