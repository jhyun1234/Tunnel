## 겹쳐 보면 (우리 판단 — 사실은 위 표와 본문의 출처)

1. **"캐고 나가면 끝"을 넘는 할 일은 대부분 전기·연료·수리다.** 열두 게임 중 여덟(Bunker · DRG · Alien · DbD · TCSM · Still Wakes · VotV · Dead Space). 고치는 행동이 소리를 내는 게임(DbD 폭발, TCSM 소리 막대, TCSM 밸브 증기)은 우리 "소리를 내야 돈, 소리를 내면 죽음"과 같은 규칙으로 이어진다.
2. **넓은 곳 하나 + 좁은 길, 크기 차이를 크게.** DRG(거대한 동굴 ↔ 아주 좁은 통로, "미로처럼 느껴지면 안 된다"), TCSM(좁은 지하 → 트인 바깥의 안도감), Still Wakes(좁은 기관부 ↔ 넓은 갑판), RE2(높은 가운데 홀).
3. **막다른 곳 대신 고리, 그리고 한 번 열면 생기는 지름길.** Alien(막다른 방·일자 복도 없음), RE2(열쇠 하나가 여러 문 → 지름길), Dead Space(구역 안 고리), Unexplored 해설(A52 A53).
4. **안전한 거점 + 시간이 가면 나빠지는 것이 밖으로 밀어낸다.** Bunker 발전기 연료, VotV 변압기, Lethal 자정 출발.
5. **같은 크기 칸만 이어 붙이면 격자 느낌이 난다** — SCP 가 그 예. MAP3 두 판(8 m 칸)도 여기에 가깝다.

### 1. Amnesia: The Bunker (2023, Frictional Games)

#### 1-1. 전체 짜임 (위에서 본 모양)

- **가운데 거점 1개 = Central Bunker.** 안에 Administration Room(세이브하는 유일한 방, 물건 보관함, 벙커 전체 지도, 자물쇠 달린 금속문 2개)이 있고, 그 방에서 계단으로 내려가면 **Generator Room**(벙커 전체 전등을 켜는 발전기)이 있다 [A3][A7][A8].
- 시작 방(Sickroom)은 Central Bunker 북쪽이다 [A7]. Administration Room을 지나면 **긴 복도(long hallway)**가 나오고 여기서 가지가 갈라진다: 왼쪽 → Officer Quarters, 건너뛴 가지 → Mission Storage(문을 폭파하거나 옆 환기구로 들어감), 막다른 끝 → 무너진 **탈출구**(마지막에 폭약으로 뚫는 곳) [A7].
- 복도의 **Lockdown Wheel**을 돌리면 막혀 있던 날개들(Soldier Quarters, Arsenal, Prison, Maintenance)이 열린다 [A13].
- 날개끼리 뒷길: Maintenance는 Officer Quarters를 거쳐 들어간다 [A5]. Arsenal 안 왼쪽 복도가 Officer Quarters로 이어진다는 공략 문장도 있으나 어느 사이트 글인지 특정하지 못했다 **(확인 못 함)**. Arsenal 너머에 더 깊은 **Tunnels(로마 유적)**가 있다 [A5][A13].
- 지도상 구역은 모두 **6개** [A8].
- 다시 그리기용 도식:
  ```

          |              |            |            |
   [Officer Q]    [Soldier Q]    [Prison]    [Arsenal] --- [Tunnels(가장 깊음)]
      |    \_________________________________/  (Arsenal↔Officer Q 뒷길 — 확인 못 함)
   [Maintenance]
  ```

#### 1-2. 크기·시간

- 한 판 평균 4~6시간(감독 Fredrik Olsson) [A1]. HowLongToBeat 본편 평균 약 4.5시간(검색 요약만) [A11].
- 감독은 "꽤 작은 환경(fairly small environment)"이라고 말했다 [A4].
- 발전기: 연료 한 통 = 연료 게이지 2칸 [A9]. 가득 채우면 60분(검색 요약만, 팬 위키) [A10].
- m 단위 크기, 방 개수: **(확인 못 함)**.

#### 1-3. 할 일(목표)이 맵에 어떻게 흩어져 있나

- 큰 목표 사슬 [A5]: Wheel(Mission Storage) → Arsenal 비밀번호(Soldier Quarters 통신실) → 폭약(Arsenal) → Wrench(Maintenance) → Bolt cutters(Prison) → 기폭 손잡이(Arsenal 너머 Tunnels) → 거점 복도의 막힌 탈출구 폭파.
  → **날개마다 목표 하나**씩 놓여 있어서 거점을 중심으로 날개를 번갈아 다녀와야 한다.
- **발전기 = 되돌아오게 만드는 시계.** 연료가 계속 타서, 떨어지기 전에 거점으로 돌아와 채워야 한다 [A1][A3]. 연료통은 벙커 곳곳에 흩어져 있고, Maintenance의 Fuel Storage에는 빈 병만 있으면 무한히 채울 수 있는 큰 통이 있다 [A9].
- 숨어 있는 시간도 연료를 태운다 — 오래 숨으면 손해 [A3].
- 불이 켜진 방에서는 괴물이 벽 밖으로 덜 나온다 [A9]. 즉 "전기 유지"가 곧 안전이다.
- 수리형 목표: 발전기 연료 채우기, Lockdown Wheel 교체가 여기에 해당한다 [A5][A9].

#### 1-4. 넓다 vs 답답하다

- 벙커 자체가 좁은 편이다("fairly small") [A4]. Arsenal은 창고 칸들이 미로처럼 늘어선 구역이다 [A2].
- 넓은 방·높은 천장이 있는지 출처는 **(확인 못 함)**.
- 대신 **밝기**가 공간 느낌을 바꾼다: 불 켜진 곳 = 비교적 안전, 불 꺼진 곳 = 괴물 구역 [A1][A9].

#### 1-5. 길 찾기

- 들고 다니는 지도·미니맵이 **없다.** Administration 벽의 큰 지도로만 본다 [A8].
- 처음에는 Central Bunker와 Officer Quarters만 보이고 나머지 4구역은 회색이다. 각 구역 입구의 잠긴 Clerk's Office를 벽돌·폭발물로 부수면 그 구역 지도 조각이 거점 지도에 붙는다 [A8].
- 지도에 표시를 해 두고 다닐 길을 계획한다 [A8].
- 환기구 샛길: Lounge, Mission Storage 등 [A7].

#### 1-6. 괴물이 다니는 길

- 괴물(Beast)은 **벽 속 구멍들 사이를 기어서** 이동한다 [A2]. 길이 없으면 벽을 통과해서라도 경로를 찾는다 [A2].
- 불이 켜져 있을 때: 구멍을 무작위로 골라 다녀서 플레이어가 먼지 흔적을 보게 만든다. 전기가 꺼지면: 구멍 망으로 들어가 플레이어에게서 가장 먼 구멍으로 간다 [A2].
- 괴물은 소리를 듣고 오고, 어둠을 좋아한다 [A1].
- 괴물이 부술 수 있게 나무 물건을 일부러 많이 두었다 [A2]. Arsenal은 문을 열기 전엔 괴물이 나오지 않게 막았다(맵이 너무 부서질까 봐) [A2]. Tunnels에서는 괴물이 활동하지 않는다 [A2].
- 처음엔 괴물을 밝은 곳에 두었다가, 개발 중간에 **벽 구멍 속**으로 옮겼다 [A4].
- 구역은 한 번에 하나씩 불러온다(지나갈 때 잠깐 멈춤) [A2].

#### 1-7. 판마다 바뀌나

- 지도 모양은 **고정**이다 [A2][A3].
- 바뀌는 것: 아이템·자원 위치, 함정 위치, 문 비밀번호 값 [A1][A3]. 괴물이 고르는 구멍과 머무는 시간도 무작위다 [A2].
- Arsenal 안 배치가 무작위라는 공략 주장이 있다 [A5] — 개발자 확인은 **(확인 못 함)**.

### 2. Lethal Company (Zeekerss) — Factory / Mansion / Mineshaft

#### 2-1. 전체 짜임

**공통:** 바깥(착륙한 배) → **정문(Main Entrance) 1개** + **비상구(Fire Exit) 최소 1개**(March는 3개) → 실내 [A18]. 비상구의 바깥 위치는 고정이지만, 안쪽에서 어디로 열리는지는 매번 다르다. 비상구 쪽은 정문 쪽과 **잠긴 문으로 갈라져 있는 경우가 많다** [A18].

**조립 방식:** 실내는 Unity 에셋 **DunGen**으로 방 조각(tile)을 이어 붙인다 [A26]. DunGen은 시작 방 → 목표 방까지 **주 경로(main path)**를 먼저 만들고(길이 = 최소~최대 방 개수), 그 다음 곁가지(branch)를 붙이고, 겹치는 문끼리 일정 확률로 이어서 **고리·지름길**을 만든다 [A27]. Lethal Company 흐름은 "정문 1개 + 비상구 몇 개"를 포함하도록 짜여 있다 [A26].

- **Factory:** 입구 방(바닥 격자, 천장에 큰 선풍기) → 불빛이 드문드문한 콘크리트 **미로 복도** + 여러 갈래가 모이는 6각형 교차 방 + 깊은 구덩이 위 **catwalk** + 두 층을 잇는 계단 + 창고·서버실 + 네 갈래 길이 있는 아주 큰 **Manufacturing room** + **Apparatus room** [A15]. 보안문(security door)은 배의 터미널로 여닫는다 [A14]. 비상구는 catwalk나 작은 네모·ㄱ자 물건방으로만 열린다 [A18].
- **Mansion:** 2층 발코니가 있는 큰 로비 → 카펫 복도 → 방 14종(서재, 벽난로방, 부엌, 온실, 욕실, 침실, 파티방, 수영장, 차고 등) [A16]. 2층 구조이고 계단·서재가 층을 잇는다. 비상구는 책장 방으로만 열린다 [A16][A18].
- **Mineshaft (v60, 2024-08-17 추가) — 우리와 가장 닮음:**
  ```
  [바깥]→[정문]→[입구 방: 2층, 계단, 레일·광차]
                    |
               [작은 Elevator] (문 3곳 버튼: 안 1, 위층 1, 아래층 1)
                    |
         [아래층 복도 구역 = 허브]──[Fire Exit (여기로만 옴, 동굴에는 없음)]
            |        |        |
        [파란 불 문 / 벽 구멍] 여러 개
            |        |        |
         [동굴 가지들: 울퉁불퉁 터널, 버려진 갱도, 빠지면 죽는 구덩이, 물 찬 기어가는 터널]
  ```
  폐품(scrap)은 주로 **동굴 쪽**에 몰린다 [A14]. 비상구는 엘리베이터를 건너뛰어 아래층 복도로 바로 오지만, 동굴 안으로는 절대 열리지 않는다 [A17][A18]. 엘리베이터 버튼·운반·Masked 사용은 [A24](검색 요약만).

- **환기구(vent)**: 외계인은 환기구 안에서는 레벨 위를 직선으로 자유롭게 움직이고, 모습은 안 보이고 소리만 난다 [A40].

- 장소마다 설정이 12가지 넘게 있다. 예: Seegson Communications에서는 환기구 안에서 소리만 내고 내려오지 않는다 [A40].
- 환기구에서 튀어나와 덮치게 만들 수 있다(Gary Napper) [A41].

#### 4-7. 판마다 바뀌나

- 맵은 **손으로 만든 고정 맵** [A37]. 대신 외계인 행동을 대본으로 짜지 않아서 매번 다르다 [A37].

#### 4-8. 개발자 말

- Gary Napper: "if the Alien was scripted, you'd see the same behaviour" — 그래서 대본이 아닌 AI로 만들었다 [A37].

#### 4-9. 우리 게임에 가져올 것

- **모든 방에 출입구 2개 이상 + 괴물 전용 샛길**(환기 갱도·천장 구멍)을 두어 막다른 방을 없앤다. 수리 스위치 근처는 괴물이 바로 옆에 서지 않게 해서 "조작할 틈"을 준다.

### 5. 공포 맵 설계 원칙 (여러 출처 공통)

A1. **트인 곳과 숨을 곳을 번갈아 둔다 (Prospect–Refuge).** 트인 곳 = 드러나서 불안, 반쯤 막힌 곳 = 밖은 보이고 나는 안 보여서 안심. 좁은 통로는 도망갈 길을 없애 무섭다. 이 둘을 번갈아 배치해 긴장의 리듬을 만든다. 공포 게임은 안전해 보이는 곳을 위험하게 뒤집기도 한다. — Christopher Totten [A51]
A2. **막다른 가지 대신 고리(loop)로 잇는다.** 나뭇가지 모양 맵은 막다른 곳과 되돌아가기가 많다. 입구와 목표를 두 갈래 길로 잇는 고리 구조는 길이 둘이라 선택이 생기고, 잠긴 문·지름길 고리를 겹치면 사람이 만든 것처럼 느껴진다. — Joris Dormans(Unexplored) 해설 [A52][A53]. DunGen도 겹치는 문을 이어 고리·지름길을 만드는 설정이 있다 [A27].
A3. **꼼짝없이 갇히는 방을 만들지 않는다.** 방마다 출입구 여러 개, 괴물과 플레이어가 같이 쓰는 샛길(바닥 밑·환기구), 숨을 곳. 괴물이 사방에서 올 수 있을 만큼 넓게, 하지만 늘 도망칠 길은 있게. — Alien: Isolation [A38]
A4. **거점 + 시계로 밖으로 밀어낸다.** 안전한 방은 한 곳(세이브·계획), 그 방을 유지하는 자원(발전기 연료)이 계속 줄어서 결국 밖으로 나가야 하고, 숨어서 버티는 시간도 손해가 된다. — Amnesia: The Bunker [A3][A9]
A5. **큰 방을 굵기가 다른 통로로 잇고, 방 모양이 다음 출구로 이끈다.** 미로처럼 느껴지면 안 되고, 거대한 동굴과 아주 좁은 통로를 섞는다. — Deep Rock Galactic [A29][A30]
A6. **안전 구역과 위험 구역을 분명히 하고, 긴장 뒤엔 숨 돌릴 틈을 준다.** 추격 전에는 적의 행동과 지형을 미리 보여 주고, 추격 중에도 선택(문 막기 등)이 있게 한다. — Jared Mitchell, Game Developer [A54]

### 1. Dead by Daylight (DbD)

**1. 전체 짜임**
- 네모난 바깥 울타리 안에 칸(tile)을 깐 맵. 칸은 대부분 16×16 m(8×8 m 네 개)이고, 미리 만든 칸을 넣고 돌려서 매번 다르게 보이게 한다[B2].
- 칸 종류: 맵마다 고유한 **큰 건물 1**(main building), **킬러 오두막 1**(shack), 나머지는 채움 칸(filler), 가장자리 칸(edge)[B2].
- 그림으로: `바깥 울타리 네모 — 안에 큰 건물 1 + 오두막 1 + 채움 칸 여럿 — 울타리 벽에 출구 문 2개(위치 무작위)`[B2][B4].
- 실내 맵(RE2 경찰서 맵, Midwich 학교)은 칸을 쓰지 않고 원작 건물을 그대로 옮김[B2].

**2. 크기·시간**
- 평균 맵 넓이 약 9,358 m²(8×8 m 칸 146개), 가장 작은 맵 6,272 m², 가장 큰 맵 12,800 m²(2v8 모드)[B3]. 평균은 대략 97 m × 97 m 네모에 해당(계산).
- 발전기 7개가 생기고 **그중 5개**를 고쳐야 출구 문에 전기가 들어온다[B1]. 혼자 고치면 1개에 90초[B1].
- 한 판 길이: 생존자 기준 8~9분쯤이라는 플레이어 관찰뿐, 공식 통계 없음(확인 못 함)[B5].

**3. 할 일이 어떻게 흩어지나 / 수리 동작**
- 발전기 자리는 맵마다 정해진 후보 자리가 있고, 후보가 7개보다 많아서 판마다 어느 자리에 생길지 달라진다[B1].
- 수리 = 버튼을 누르고 버티기. 중간에 무작위로 **스킬 체크**(타이밍 누르기)가 뜬다. 실패하면 진행 −10%, 발전기가 **폭발하고 킬러에게 '큰 소리 알림'**이 가며, 3초 동안 진행이 멈춘다[B1]. 잘 맞추면 +1%[B1].
- 킬러는 발전기를 걷어차 진행을 되돌릴 수 있다(−5% 즉시, 그 뒤 초당 조금씩 감소)[B1].
- 5/7이라서 "가까운 것만 골라 고치기"가 가능하지만, 결국 흩어진 자리들 사이를 오가며 킬러와 마주친다.

**4. 넓다 vs 답답하다**

**5. 길 찾기** — 큰 건물·오두막 같은 큰 칸은 늘 같은 자리(작은 칸만 돌려 넣음)라서 이것이 이정표가 된다[B2]. 출구 문은 울타리 벽 안에서 무작위[B4].

**6. 위협이 다니는 길** — 킬러는 맵 전체를 자유롭게 다닌다. 발전기 실패 폭발이 킬러를 그 자리로 불러온다[B1].

**7. 판마다 바뀌나** — 큰 칸 위치는 고정, 작은 칸의 종류·회전, 발전기 자리, 출구 문 자리는 바뀜[B1][B2][B4].

**8. 개발자 말** — 게임 디렉터 Mathieu Côté: "The uncertainty of the procedural map" 가 긴장감의 원인 중 하나라고 말함[B6].

### 2. The Texas Chain Saw Massacre (2023)

**1. 전체 짜임**

### 3. Still Wakes the Deep

**3. 할 일 / 수리 동작**
- 주인공이 **전기공**이라 고칠 일이 많다: 가스 누출 밸브 잠그기, 스위치 5개를 정해진 순서(기관부 → 처리동 → 관리동 → 갑판 → 거주동)로 올려 발전기 재가동, 조종실 조명 복구, 밸러스트 조종 복구 등[B17].
- **Addair 구간**(괴물이 도는 구역 안에서 수리): 진흙 처리/발전기 방 둘레와 가운데에 기어가는 틈이 있고, 맞은편에 제어실이 있다. 할 일 4단계 = 틈으로 제어실 가기 → 스위치 순서대로 올리기 → 열쇠로 발전기 재시동 → 괴물이 다시 나타난 뒤 계전기 되돌리기. 점검 통풍구가 제어실과 발전기를 잇는다[B18].
- 괴물은 순찰하고, 던진 물건 소리에 반응하지만 금방 순찰로 돌아간다[B18]. 싸움 없음 — 숨기(물건 뒤·통풍구)·던져서 유인만 있음[B15].

**4. 넓다 vs 답답하다** — 폭풍 치는 넓은 갑판 ↔ 기관부처럼 **"narrow, the ceiling is low, every surface is metal"**(리드 디자이너 Rob McLachlan)인 창 없는 구역을 번갈아 씀[B19]. 이야기가 진행되며 구역이 부서지고 **물에 잠겨** 새 길이 생긴다[B15].

**5. 길 찾기** — 가야 할 곳에 **노란 페인트**를 칠해 안내[B15].

**6. 위협이 다니는 길** — 구역마다 정해진 괴물이 정해진 곳을 순찰(세탁실, 화물 구역, 침수 구역 등)[B17][B18].

**7. 판마다 바뀌나** — 안 바뀜(일직선 이야기)[B15].

**8. 개발자 말** — McLachlan은 다시 만든다면 시추선 이동을 더 자유롭게, 길을 고르고 되돌아갈 수 있게 하고 싶다고 함(요지)[B19]. 너무 가혹하고 예측 불가능한 조우 요소(체력 게이지, 바람 저항, 강화된 괴물 감지)는 뺐다(요지)[B19].

**9. 우리 게임에 가져올 것**

### 4. Dead Space (2023 리메이크)

**1. 전체 짜임**
- 채굴선 USG Ishimura를 로딩 없이 **하나로 이어진 배**로 만들었다. 구역 6개: 기관/채굴(Engineering/Mining), 수경재배(Hydroponics), 비행갑판/격납고, 의료, 승무원 숙소, 함교[B22].

**2. 크기·시간** — 12장(chapter)[B29]. 배 크기·총 플레이 시간 수치는 확인 못 함.

- 5장: 재생하는 괴물 Hunter가 의료 구역에서 목표 내내 여러 번 따라오고, 마지막에 냉동실로 유인해 얼린다[B28].

**5. 길 찾기** — 트램 역이 기준점. 잠긴 문 → 보안 등급 → 다시 오기(메트로배니아식)[B22][B25].

**6. 위협이 다니는 길** — **Intensity Director**: 약 350개 사건을 1~11 강도로 매겨, 구역마다 다른 강도 곡선으로 뿌림[B23]. 3D 소리가 이어진 방을 따라 퍼져 미리 알린다[B23]. 5장 Hunter는 추적자형[B28].

**7. 판마다 바뀌나** — 배 구조는 고정, 사건·적 배치가 Intensity Director로 달라짐[B23].

**8. 개발자 말** — 기술 감독 David Robillard: "You want the ups to be high and the lows to be low."[B23]

**9. 우리 게임에 가져올 것**
- **전력 나눠 쓰기**: 발전기 힘이 모자라 "충전실 조명 / 펌프 / 압축기" 중 둘만 켤 수 있게 → 조명을 켜면 안전하지만 괴물이 빛을 보고 옴(우리 괴물은 빛도 추적)(우리 판단).

### 6. SCP: Containment Breach

**1. 전체 짜임**
- **20×20 격자**, 한 칸 = 방 하나. 개발자가 방 크기를 8×8 m로 잡음[B38].
- 방 모양은 이어진 문 수로 5종: 막다른 방(1), 곧은 복도(2), 꺾인 복도(2C), T자(3), 네거리(4)[B38].
- 길은 격자 **위에서 아래로** 파 내려가며 옆으로 무작위 가지를 친다[B38].
- 구역 3개: 경(輕)격리 구역(흰색), 중(重)격리 구역(빨강), 입구 구역(노랑), 사이에 **검문소 줄**(검색 요약)[B39]. 출구 Gate A·Gate B는 입구 구역에 있음[B37](검색 요약)[B40].
- 그림으로: `위 층: 경격리 → 검문소 → 가운데: 중격리 → 검문소 → 아래: 입구 구역 → 출구 2개`.

**2. 크기·시간** — 판 길이·출구까지 걸리는 시간 수치 확인 못 함.

**3. 할 일** — 수리보다 **카드키 등급**을 올려 가며 문 열기(1등급 → 2등급 …)[B40](검색 요약). 시설 도면을 문서·단말기로 얻음[B37].

**4. 넓다 vs 답답하다** — 대부분 같은 크기 칸의 방·복도. 넓이 차이에 대한 자료는 확인 못 함.

**5. 길 찾기** — 구역마다 색·분위기가 다름[B39], 검문소가 경계.

**6. 위협** — 괴물마다 **감각이 다름**[B37][B40]:
- SCP-173: 보고 있으면 못 움직이고, **눈을 깜빡이는 순간** 다가옴[B37].
- SCP-106: 벽을 통과해 따라옴[B37][B40].
- SCP-939: 정해진 방향으로 순찰, **웅크려 걸으면 소리를 못 들음**[B40](검색 요약).

**7. 판마다 바뀌나** — 매 판 **시드 문자열**로 맵이 새로 생성됨[B37].

**8. 개발자 말** — Regalis(개발자, 포럼): "I thought 8x8 meters would be a good room size"[B38].

**9. 우리 게임에 가져올 것**
- 격자 생성 자체는 쓸 수 있지만, **같은 크기 칸만 이어 붙이면** 우리 초안처럼 "격자" 느낌이 난다. 크기가 다른 특별 방(설비실·큰 채굴장)과 구역별 색을 섞어야 한다(우리 판단).
- 괴물 감각을 분명히 나누기(소리 / 빛): 173의 "안 볼 때만 움직임"처럼 규칙이 한 줄로 설명되게(우리 판단).

**10. 지도 이미지** — 판마다 생성되어 고정 지도 없음[B37].

### 7. R.E.P.O.

**1. 전체 짜임**
- 판마다 **모듈(방 조각)** 을 이어 붙여 시설을 만든다[B41][B46].
- 트럭이 도착하는 방에 **첫 추출 지점**이 늘 있고, 추가 추출 지점은 대개 **도착 지점의 반대쪽 끝**에 있다(검색 요약)[B42].
- 그림으로: `트럭 도착 방(추출 지점 1) — 모듈 방들이 가지처럼 — 반대쪽 끝에 추출 지점 2~4 — 다 채우면 트럭으로 복귀`.

**2. 크기·시간** — 레벨 1은 추출 지점 1개, 2~5는 2~3개, 6~9는 4개(공략 사이트 기준)[B43]. 한 판 시간·맵 넓이 수치는 확인 못 함. 최대 6명 협동[B41].

**3. 할 일** — 값나가는 물건을 **물리로 들어서** 추출 지점까지 옮겨 할당량을 채운다. 물건이 부딪혀 **망가지면 값이 깎인다**[B41]. 추출 지점을 차례로 채운 뒤 트럭으로 돌아가야 끝(검색 요약)[B42].

**4. 넓다 vs 답답하다** — 레벨이 오를수록 "더 크고 미로 같아진다"(요지)[B43]. 구체 자료는 확인 못 함.

**5. 길 찾기** — 다음 추출 지점이 **미니맵에 목표로 표시**됨(검색 요약)[B42].

**6. 위협**
- 거의 모든 괴물이 소리(떨어뜨린 물건, 달리기 등)를 들으면 **그곳으로 길을 바꿔 조사**하러 온다. 소리마다 크기가 다른 '소리 거품' 안의 괴물만 듣는다(검색 요약)[B45].
- **Huntsman**: 앞을 못 보지만 모든 소리를 듣는다 — "All sounds will alert the Huntsman."[B44] 반대로 Headman·Reaper는 눈으로 찾는다[B44]. 가구 밑에 웅크리면 대부분의 큰 괴물을 피함[B44].

**7. 판마다 바뀌나** — 방 배치·물건·괴물 배치가 매 판 바뀜[B41].

**8. 개발자 말** — 찾지 못함(확인 못 함).

**9. 우리 게임에 가져올 것**
- 우리 루프(케이지 → 캐기 → 케이지)는 R.E.P.O.와 같은 뼈대. **광석을 들고 오면 느리고 떨어뜨리면 소리** → 욕심의 대가(우리 판단).
- 괴물 1마리지만 "소리 = 조사하러 옴, 빛 = 눈으로 찾음"을 나눠 쓰면 Huntsman·Headman 두 종류 효과(우리 판단).

**10. 지도 이미지** — 판마다 생성되어 고정 지도 없음[B41].

### 8. Voices of the Void

**1. 전체 짜임**
- 가운데 **Alpha Root Base**(기지) + 둘레에 **위성 접시**들(B~Y 알파벳 이름) + **변압기 3개**[B47][B49]. 접시마다 작은 서버실이 있음[B49].
- 그림으로: `가운데 기지 1 — 둘레에 접시 여러 개 — 변압기 3개 — 사이는 숲과 길`. 접시 배치 모양(고리·격자)은 확인 못 함.

**2. 크기·시간** — 서버 54개 = 기지 서버실 30 + 접시 24[B47][B48]. 이동 속도: 걷기 400, 달리기 800, ATV 2000 (게임 단위/초)[B47]. 하루 단위로 진행, 자정마다 새 과제 메일[B47]. 맵 넓이는 확인 못 함.

**3. 할 일 / 수리 동작**
- 서버가 고장 나면 기지 기능이 느려진다. 고장 난 서버는 **빨간불 깜빡임**, 정상은 초록불[B48](검색 요약).
- 고치기 = 무작위로 골라지는 **미니게임**[B48].
- 변압기는 전력이 조금씩 줄고, 매일 **무작위로 하나**가 주로 닳는다. 0이 되면 기지 전체 정전 → **직접 가서 빨간 버튼**으로 재가동[B47].

**4. 넓다 vs 답답하다** — 넓은 바깥 숲 ↔ 좁은 기지 실내·접시 서버실. 자세한 자료는 확인 못 함.

**5. 길 찾기** — 기지 통제실 입구 왼쪽 벽에 접시 위치 지도(검색 요약)[B51]. 콘솔 명령으로 고장 서버·변압기 상태 확인[B47][B48].

**6. 위협** — 예: Abandoned Kerfur는 **기지에서 정확히 200 m 떨어진 원** 어딘가에 생기고, 켜지면 플레이어 쪽으로 다가와 찌른다[B50]. 잠을 못 자면 Insomniac이 나타남[B47]. 소리·빛 반응 자료는 없음[B50].

**7. 판마다 바뀌나** — 매일 닳는 변압기가 무작위로 바뀜[B47]. 서버 고장 규칙은 확인 못 함[B48].

**8. 개발자 말** — 찾지 못함(확인 못 함).

**9. 우리 게임에 가져올 것**
- "**정전되면 나가서 고친다**": 케이지 근처 설비(충전·펌프·압축기) 중 하나가 판마다 무작위로 멈춤 → 밝은 허브에서 어두운 갱도로 나갈 이유가 생김(우리 판단).
- 고장 표시를 **빨간불/초록불**처럼 멀리서 보이게(우리 판단).

**10. 지도 이미지** — 위키의 인터랙티브 지도 페이지: https://voicesofthevoid.wiki.gg/wiki/Locations (이미지 직접 URL 확인 못 함)

### 9. 여덟 게임을 겹쳐 본 결론 (모두 우리 판단)

B1. **"캐고 나가기만 하면 단순한가?"** — 여덟 중 다섯(DbD, TCSM, Still Wakes, Dead Space, VotV)이 **흩어진 설비 수리**를 "나가는 조건"으로 쓴다. R.E.P.O.만 "캐서 들고 오기"가 중심인데, 그것도 추출 지점을 **반대쪽 끝**에 두어 맵을 가로지르게 만든다. → 우리도 "광석 = 점수, 설비 수리 = 케이지 전원(나가는 조건)"으로 나누면 두 축이 생긴다.
B2. **수리 행동이 소리를 낸다**: DbD 스킬 체크 실패 폭발, TCSM 연타 소리 막대, TCSM 밸브 증기. 우리 "곡괭이 = 소리" 규칙을 수리에도 똑같이 적용하면 규칙이 하나로 이어진다.
B3. **답답함 해결**: RE2 경찰서(가운데 홀 + 날개 고리 + 열면 생기는 지름길), Dead Space(허브 + 바퀴살 + 고리), TCSM(좁은 지하 → 넓은 바깥의 안도감), Still Wakes(좁은 기관부 ↔ 폭풍 갑판). 공통점은 **넓은 곳 하나 + 고리 길 + 막힌 곳을 여는 지름길**. SCP식 **같은 크기 칸 격자**만으로는 이것이 안 생긴다.
B4. **3~5분 데모 크기 감**: DbD는 발전기 1개 혼자 90초 × 5개 = 450초(7.5분)의 수리 작업량을 4명이 나눠 하는 규모[B1](계산). 혼자 하는 3~5분 데모라면 수리 2곳(각 20~30초) + 채굴 몇 번 정도가 상한으로 보인다.
