# 제안서 UI-1c — 갱도 화면 글자 0 (숫자·안내 글자를 지우고, 소음 원은 DevHud 로)

작성 2026-09-16. 출처: `docs/design/ui_ux_design.md` Step 1(화면 위 = 갱도 밖에서만 숫자) · Step 6(DevHud 2줄·5줄) · Step 7 UI-1 ③ · 결정 변경 제안 1·2·3. UI-1 네 가지 중 세 번째 — ① 내구도·② 지쳤을 때 자세는 09-16 통과. 남은 것: ④ DevHud 시작 시 끄기.

## 무엇을 하려는지
갱도 안에서는 **글자와 숫자가 하나도 안 뜬다.** 지금 왼쪽 아래에 있는 "철 N", "곡괭이 없음 — E 로 줍기", "곡괭이 부러짐" 을 지운다. 광석 수는 갱도 밖(검수대·상점, 나중)에서만 본다. 소음 원(내가 낸 소리 크기)은 판정용이라 DevHud 를 켰을 때만 그린다. 글자 대신 **세상이 알려준다**: 곡괭이가 없으면 손이 비어 있고(이미 그렇다), 던진 곡괭이에 2.5 m 안으로 다가가면 곡괭이 머리가 살짝 빛나 "여기, 주울 수 있다"를 보여준다. 이유: 갱도 안 숫자는 공포를 깎고, 안내 글자는 튜토리얼이 된다(설계서 기준 ①·②).

## 지금 상태와 다른 점
- `MiningHud.cs` 가 왼쪽 아래에 "철 N"(항상), "곡괭이 없음 — E 로 줍기"/"곡괭이 부러짐"(빈손일 때), 소음 원(소리 낸 뒤 1 s)을 그린다.
- 판정 통과한 것을 바꾼다: M2 "소음 원은 그대로 둠" → DevHud 로, M6 "곡괭이 없음 글자" → 삭제 + 머리 빛남. 설계서 결정 변경 제안 1·2·3 그대로.

## 어떻게 만들 것인지
- **글자 삭제** (`MiningHud.cs`): "철 N" 줄과 빈손 줄을 지운다. 파일은 남기고 소음 원만 그린다 — 씬은 안 바꾼다.
- **소음 원 → DevHud** : `DevHud.Visible`(F1 상태) 이 참일 때만 원을 그린다. DevHud 플레이어 줄에 `ore N` 과 `noise 종류 반경 m 남은 s`(마지막 소음)를 글자로 더한다(설계서 Step 6 2줄).
- **곡괭이 머리 빛남** (`ThrownPick.cs`·`BuildM1.cs`): 던져진 곡괭이가 착지한 뒤 플레이어가 CARRY_REACH 2.5 m 안에 있으면 `PICK_Head` 렌더러 재질을 Unlit 빛남 재질(`M7_PickGlow.mat`, 괴물 눈과 같은 방법 — Lit+발광은 빌드에서 안 나온다)로 바꾸고, 벗어나면 원래 재질로. 재질은 씬 생성기가 만들어 넣으므로 **`MakeScene -force` 한 번**(M1_Volume·M2_Dust·M3_StalkerBody·M4_StalkerEye 도 다시 만들어진다 — 정상).
- **검사** `-only hud`: ① DevHud 꺼진 채 소음을 내고 곡괭이를 던져 빈손일 때, 플레이어 화면에 그린 글자 수 0(`MiningHud.labelsDrawn`) · 왼쪽 아래 300×120 px 에 흰 픽셀(밝기 > 0.9) 0 · 소음 원 안 그림(`circlesDrawn` 0) ② DevHud 켜면 소음 원이 그려진다(`circlesDrawn` ≥ 1) ③ 던진 곡괭이에서 4 m: 머리 재질 원래 것·램프 끄고 머리 영역 밝기 < 0.02, 2 m: 빛남 재질·밝기 > 0.05(M4 눈 검사 0.143 과 같은 방식), 주우면 재질 원래대로. 사보타주: `hudtext`("철 N" 을 다시 그린다 → ①) · `noglow`(빛남 없음 → ③).
